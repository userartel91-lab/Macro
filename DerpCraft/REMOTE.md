# Пульт по Wi-Fi (API для телефона)

Игра поднимает маленький HTTP-сервер в домашней сети. С ним работает мидлет **DerpCraft Remote** (`tools/midlet/`), но подойдёт всё, что умеет открыть ссылку: браузер, `curl`, скрипт на Python.

## Включение

- Сервер включён сразу. Адрес и PIN видны **внизу слева в главном меню** и пишутся в чат, когда открываешь мир. Ещё их показывает команда `/remote`.
- Настройки лежат в `game\remote.txt` (`enabled`, `port`, `pin`). Их можно менять и из игры:
  - `/remote off` и `/remote on` выключают и включают сервер;
  - `/remote pin 4821` задаёт свой PIN (от 4 до 8 цифр);
  - `/remote port 25580` меняет порт (по умолчанию 25580).
- **Windows**: при первом запуске брандмауэр спросит про Java. Разреши доступ в **частных сетях**. Если окно уже закрыто, открой *Брандмауэр Защитника Windows → Разрешение взаимодействия с приложением* и отметь `Java(TM) Platform SE binary` для частных сетей.
- Компьютер и телефон должны быть в одном Wi-Fi. Гостевая сеть роутера часто не пускает устройства друг к другу.

## Запросы

Все запросы — `GET http://<IP>:<порт>/<запрос>?p=<PIN>&...`. Ответ — текст в UTF-8. Первая строка `OK` или `ERR причина`, дальше строки `ключ=значение` или строки с полями через Tab. Строки, которые начинаются с `> `, — это новые сообщения чата, которые появились после команды.

Запрос выполняется в главном потоке игры между кадрами, поэтому он делает ровно то же, что клавиша, клик или команда в чате.

| Запрос | Что делает |
|---|---|
| `/ping` | проверка связи, PIN не нужен; `auth=ok`, если PIN верный |
| `/status` | состояние: `world`, `screen` (открытое меню), `fps`, `mode`, `time` (0..23999), `day`, `cycle`, `x y z yaw pitch`, `hp`, `food`, `fly`, `flyspeed`, `slot`, `held`, `cam` (player/free/orbit/path), `tripod`, `keys` (ключи пути), `path`, `progress`, `focal`, `roll`, `dof`, `focus`, `view`, `hud`, `smooth`, `selfie`, `rec`, `scene`, `playing`, `chat` |
| `/key?k=<id>` | нажать и отпустить клавишу действия. `id` берётся из `/keys`, туда входят и клавиши модов. `&s=1` — с зажатым Shift (орбита вокруг себя, автофокус, очистка пути) |
| `/key?k=<id>&a=down` / `a=up` | зажать или отпустить (ходьба, прыжок, зум, крен, ломать). Можно перечислить несколько id через запятую. **Зажатая клавиша отпускается сама через 1,2 с**, если её не подтвердить ещё раз. Пульт подтверждает каждые 0,35 с, поэтому при обрыве Wi-Fi ничего не залипнет |
| `/release` | отпустить всё |
| `/keys` | все действия: `id`, категория, название, клавиша |
| `/cmd?c=<команда>` | любая команда чата (`/` можно не писать). В ответ приходят сообщения, которые она вывела |
| `/say?t=<текст>` | написать в чат |
| `/log?since=<n>` | строки чата после номера `n`; `n=` — текущий номер |
| `/raw?c=<GLFW-код>&m=<mods>` | «сырая» клавиша, работает и в меню: 256 Esc, 257 Enter, 258 Tab, 259 Backspace, 262–265 стрелки |
| `/type?t=<текст>` | ввести текст в открытое меню (поиск, имя мира, табличка) |
| `/click?x=0..1&y=0..1&b=0` | клик в точку картинки: в меню нажимает кнопку, в игре работает как клик мышью (b: 0 левая, 1 правая, 2 средняя) |
| `/look?dx=<град>&dy=<град>` | повернуть взгляд игрока или свободной камеры |
| `/scroll?d=1` | колёсико: слот, скорость полёта, прокрутка меню |
| `/frame?w=432&h=243&q=55` | один кадр с экрана в JPEG (`&f=png` — в PNG), вместе с HUD и меню |
| `/worlds` | список миров: папка, имя, режим |
| `/open?w=<папка>` | открыть мир |
| `/leave` | сохранить мир и выйти в главное меню |
| `/options` | настройки: имя, тип, значение, мин, макс, шаг, название |
| `/option?n=<имя>&v=<значение>` | изменить настройку: число, `on`/`off`, `toggle`, `+` или `-` (на один шаг) |

## Живой видоискатель (порт + 1)

Для живой картинки есть отдельный сокет на **порту сервера + 1** (по умолчанию 25581), без HTTP на каждый кадр:

1. Подключись по TCP и отправь строку `DCV1 <PIN> <макс. ширина> <макс. высота> <качество 10-95>\n`.
2. В ответ придёт `OK\n` (или `ERR ...`).
3. Дальше каждый кадр — это 4 байта длины (big-endian) и JPEG.
4. За каждый кадр, который готов принять, отправляй один байт `+`. Пульт шлёт два в начале и по одному после каждого полученного кадра. Так игра никогда не отправит больше, чем успевает показать телефон, и задержка не копится.

Игра уменьшает кадр на видеокарте (цепочкой линейных уменьшений вдвое) и читает обратно только маленькую картинку, поэтому поток почти не нагружает игру. Потолок — **30 кадров/с**. Реальная скорость зависит от того, как быстро телефон расшифровывает JPEG. Пульт показывает её в строке состояния, а с размером «Средне» или «Мелко» кадров заметно больше.

## Новые команды (работают и из обычного чата)

- `/cam player|free|orbit [радиус высота скорость]|orbitme|tripod [on|off]|key|undo|clear|play [секунды] [on]|stop|lens <мм|0>|zoom <±мм>|roll <°>|tilt <±°>|level|dof [on|off]|f <диафрагма>|focus <м|here|center|player>|letterbox [0-4]|shake <0-1>|blur <0-1>|flares <0-1>|grid|speed <блоков/с>|easing <0-3>|info` — киношная камера целиком, как в панели F9 и с клавиш камеры.
- `/option [имя] [значение]` — настройки игры (без аргументов выводит список).
- `/remote [on|off|pin <цифры>|port <n>]` — сам пульт.

## Примеры

```
curl "http://192.168.1.5:25580/cmd?p=1234&c=time%20set%20night"
curl "http://192.168.1.5:25580/key?p=1234&k=pathKey"
curl "http://192.168.1.5:25580/cmd?p=1234&c=cam%20play%2012"
curl -o shot.jpg "http://192.168.1.5:25580/frame?p=1234&w=1280&h=720&q=90"
```
