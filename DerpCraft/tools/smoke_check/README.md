# Дымовой тест в настоящей игре (без видеокарты)

`sh tools/smoke_check/run.sh` запускает **настоящую** DerpCraft под программным OpenGL (Xvfb + Mesa llvmpipe), создаёт плоский мир с
простой тестовой машиной и проигрывает `Scenario.java`: езда, **дрифт**, **полицейский разворот**, **переворот**, **кинематографичная
камера** (Right Alt + F8, Shift — следующий кадр), **редактор машин** (Left Alt + End: все страницы, ползунки, undo, сохранение в json),
**толкание** машины (Alt сзади). Клавиши нажимаются настоящим путём (`DerpCraft.onKey` с виртуальным модификатором `Keys.VIRTUAL_MODS`,
удержание — `Keys.HELD`). Скриншоты — в `/tmp/dc_smoke/shots` (имена по порядку сценария), журнал — `/tmp/dc_smoke/smoke.log`
(строки `[smoke] CHECK ...` — проверки чисел).

Нужны Xvfb, Mesa (`libgl1-mesa-dri`), curl, JDK 21; LWJGL с Linux-natives скачивается с Maven Central в `/tmp/dc_libs` при первом запуске
(при ответе 429 скрипт повторяет). Игра при этом идёт медленнее реального времени, но тики считаются честно (сценарий привязан к тикам).

Свой сценарий: `Scenario.build()` — шаги `SmokeMain.wait(тики, действие)` и `SmokeMain.step(условие, таймаут, действие)` выполняются по очереди;
`SmokeMain.shot(имя)` — скриншот, `SmokeMain.hold(Keys.X, true/false)` — держать клавишу, `SmokeMain.key(код, mods, удерживаемыйМодификатор)` — нажать
как с клавиатуры. Нужно только чтобы между игрой и тестом не было окна «Death» (в выживании переворот на скорости отнимает ~10 ХП:
`S().stats.health = 20` перед следующим).
