# Gun tools (offline, no LWJGL / no game window)

Everything runs with the game's own gun classes (`GunType`, `GunAnimator`, `GunHold3P`, the model loaders) compiled
without OpenGL, so a Claude session can check and look at guns without running the game. Run from the DerpCraft folder.

| Command | What it does |
|---|---|
| `sh tools/gun_check/check.sh <gun folder>` | Report: model parts (what is drawn), hand points, settings, sounds; runs the first person animation (equip, burst, walk, strafe, sprint, aim, second aim, both reloads) and checks: sight on the screen centre (both aims), the magazine hand on the magazine, the bolt hand on the bolt, the old magazine let go and the new one from the pocket, arms not stretched, the bolt never past `boltBack` (prints the bolt limits and the reload style: rifle / pistol with the magazine axis); third person hold (hands on grip / handguard). `ALL OK` / `PROBLEM ...`. Also compiles the classes to `/tmp/dc_gun_check/out` for the tools below. |
| `sh tools/gun_check/preview.sh <gun folder> [out dir]` | Pictures without the game (software renderer): `<out>/sheet.png` = first person frames (hip, equip, shot, aim, aim2, aim shot, sprint, strafe, `bolt_back` = the bolt at its back limit, `locked` = the slide held back after the last shot, every reload stage, each melee kind: `jab_wind` / `jab_strike` / `jab_hit` / `jab_back`, `swing_...`, `smash_...`), `<out>/3p/sheet.png` = the player model holding the gun from behind / front / side, looking straight / up / down / turned, hand close-ups, kick, reload stages, the melee wind-ups and hits from the side and the front (`3p_jab_hit`, `3p_jab_hit_front`...), the gun carried on the back (Left Alt + F, `GunHold3P.back`: `3p_onback_back` / `_side` / `_side_left` / `_above` / `_front` / `_close`, the arm reaching for it `3p_onback_reach` / `_reach_side`), magazines in the belt pouches (Left Alt + E, `GunHold3P.pouch`: `3p_pouches_front` / `_side`). Each frame is also a separate PNG. `GUN_PREVIEW_PARTS=1` colours the magazine red and the bolt yellow. Also prints the NPC muzzle point check. |
| `python3 -I tools/gun_check/sheet.py <dir> <frame> [<frame> ...]` | A 2-column sheet `<dir>/big.png` of chosen frames at full size (e.g. `sheet.py /tmp/gun_preview reload_30 reload_45 empty_86`). Read the PNG to look at it. |
| `sh tools/gun_check/tests.sh <gun folder>` | Numbers to compare before / after a change: `SplitTest` (a pose's Gun move carries the hands, its Arms move swings the arms, the palms stay on their points), `HandsTest` (every pose x All / Gun / Arms / arm turn: how far each palm is from the drawn point it holds; all ~0), `SyncTest` (pose smoothing: all parts arrive together), `SmoothTest` (fastest roll with 0 / 1 / 2 pose smoothing), `Hold3PTest` (third person: arm stretch and how far each palm is off its point at several looks), `ArmPoseTest` (a per pose arm turn changes only that arm in that pose), `MeleeTest` (each strike: fastest muzzle / butt at the impact, back at the hold after, palms on the gun, third person arm stretch at the hit), `SaveTest` (editor save + read back: every parameter, unknown keys kept; the editor's undo `toJson`/`fromJson` round trip; the pistol / rifle presets; on a copy). |
| `sh tools/gun_check/fist_preview.sh [out dir]` | Fist fighting (Alt + Q) without the game: `FistPoseDump` frames (coming up, guard, walk, sprint, every stage of a left straight, a right straight and a right hook; a red mark on the knuckles shows the fist turning) -> `<out>/sheet.png` (default `/tmp/fist_preview`), and `FistTest` (rigid arms, one hit per punch, the combo straight -> hook, a busy hand cannot punch, up / down). |
| `tools/gun_check/tests/Hold3PSearch.java` | Tuning: brute force search of the third person grip point (`GunHold3P.GRIP`) and body twist (`TWIST`) that keeps both palms on their points. Compile and run like tests.sh does (`java -cp /tmp/dc_gun_check/out derpcraft.gun.Hold3PSearch <gun folder>`); edit its loops / score for other goals. |

Files: `GunCheck.java` (the report), `GunPoseDump.java` / `GunPose3PDump.java` (dump view space triangles of the poses),
`preview.py` (draws them: flat shading, painter's order, arms as Minecraft boxes), `tests/*.java` (package `derpcraft.gun`).
New dump frames: add a `dump(...)` / `model(...)` call in the dump classes. The renderer is approximate (no textures on
the arms, no lighting), good for positions, sizes and what covers what.
