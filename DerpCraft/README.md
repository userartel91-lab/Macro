# DerpCraft

Клон Minecraft 1.12.2 для съёмки машиним и сериалов: креатив и выживание, строительство больших городов, быстрый рендер на большой дальности, совместимость с ресурспаками 1.12.2 и API для модов.

Язык: Java 21 + LWJGL 3 (OpenGL 4.3+). Целевая система — Windows 11 (работает и на Linux/macOS).

## Быстрый старт (Windows 11)

1. Установи **JDK 21**: https://adoptium.net/temurin/releases/?version=21 (Windows x64, `.msi`). В установщике включи *Set JAVA_HOME* и *Add to PATH*.
2. Распакуй папку DerpCraft куда угодно (лучше без кириллицы в пути).
3. Запусти **`build.bat`**. В первый раз он скачает Gradle и LWJGL (нужен интернет, 1–3 минуты).
4. Запускай игру через **`Play.bat`**.

Все данные игры лежат в папке `game\`:

| Папка/файл | Что там |
|---|---|
| `game\saves\` | миры |
| `game\resourcepacks\` | ресурспаки 1.12.2 (`.zip` или папки) |
| `game\mods\` | моды (`.jar`) |
| `game\screenshots\` | скриншоты (F2) |
| `game\recordings\` | видео встроенной записи экрана (Ctrl + F2) |
| `game\ffmpeg.exe` | положить сюда для записи экрана (см. «Запись экрана») |
| `game\options.txt` | настройки |
| `game\reflections.txt` | какие блоки блестят (отражения, см. «Шейдеры») |
| `game\shaders\` | свои пресеты шейдеров для переходов (Left Alt + ,) |
| `game\crash-reports\` | отчёты, если что-то упало |

## Чтобы выглядело точно как Minecraft

Встроенные текстуры намеренно простые (2×2 пикселя). Для настоящего вида:

- **Если у тебя установлен Minecraft 1.12.2** через официальный лаунчер, в меню *Resource Packs...* появится пункт **«Minecraft 1.12.2 (your installation)»**. Это оригинальные текстуры, шрифт, интерфейс, небо и облака прямо из твоей игры.
- Или положи любой ресурспак для **1.12.2** (`.zip`) в `game\resourcepacks\` и выбери его в меню.

Что берётся из ресурспака:
- текстуры блоков `assets/minecraft/textures/blocks/*.png` любого разрешения (16x, 32x … 256x);
- анимации с `.mcmeta` (вода, лава, морской фонарь, призмарин…);
- текстуры предметов `textures/items/*.png` и трещин `blocks/destroy_stage_0..9.png`;
- шрифт `font/ascii.png`, интерфейс `gui/widgets.png`, `gui/icons.png`, фон меню, окна `gui/container/*` (инвентарь, верстак, сундук, печь, раздатчик, воронка, креатив с вкладками), панорама главного меню `gui/title/background/panorama_0..5.png`;
- модели-сущности: сундуки (`entity/chest/*`), таблички (`entity/sign.png`), кровати (`entity/bed/*`), рука игрока (`entity/steve.png`);
- солнце, луна (фазы), облака, карты цвета травы и листвы `colormap/grass.png`, `foliage.png`.

Не поддерживается: собственные JSON-модели блоков из паков, звуки из паков (звуки есть только у машин, см. «Транспорт»).

## Генератор городов (Python)

`tools/citygen/` — генерирует целый город прямо в сохранение (улицы, небоскрёбы, дома, парки), без запуска игры. Закрой игру и запусти:
`python tools/citygen/citygen.py --world "game/saves/<мир>" --size 256 --map city.png`. Подробности и API для своих построек — в `tools/citygen/README.md`.

## Пульт по Wi-Fi (телефон)

Игрой можно управлять с телефона через домашний Wi-Fi: мидлет **DerpCraft Remote** (`tools/midlet/dist/DerpRemote.jar`, альбомный экран 432×240). Он переключает день и ночь, режимы игры, камеру (ключи пути, зум, фокус, орбита, штатив), запускает запись и сцены NPC, нажимает любые клавиши игры и модов, меняет настройки, выполняет команды и показывает видоискатель с экрана, по которому можно кликать. Адрес и PIN видны внизу слева в главном меню и по команде `/remote`. Установка — в `tools/midlet/README.md`, HTTP API для своих скриптов — в `REMOTE.md`.

## Управление

**Все клавиши можно переназначить** *(1.10)*: *Options → Controls...* — нажми на кнопку с клавишей, потом нужную клавишу или кнопку мыши (боковые тоже). Можно назначить и сочетание: зажми Ctrl / Shift / Alt (левый и правый различаются) и нажми клавишу; если отпустить модификатор без другой клавиши — назначится он сам. Esc — отмена, Backspace — без клавиши, *Reset* — вернуть стандартную, *Reset All* — все. Красным подсвечено, если одна клавиша занята двумя действиями. Клавиши модов тоже там. ## Команды

Обычные: `/help`, `/tp x y z` (`~` = относительно), `/time set day|noon|sunset|night|midnight|<тики>`, `/time stop` и `/time start` (заморозить солнце), `/gamemode survival|creative|spectator`, `/speed <множитель>` (скорость полёта), `/give <предмет> [кол-во]`, `/heal`, `/kill`, `/setblock x y z <блок>`, `/fill x1 y1 z1 x2 y2 z2 <блок>`, `/seed`.

Инструменты строительства в стиле WorldEdit (можно писать с одним или двумя слэшами):

| Команда | Что делает |
|---|---|
| `//pos1`, `//pos2` | углы выделения: блок под прицелом (или где стоишь) |
| `//set <блок>` | заполнить выделение |
| `//replace <что> <на что>` | заменить блоки |
| `//walls <блок>` | стены по периметру |
| `//floor <блок>` | нижний слой |
| `//copy`, `//paste [-a]` | копировать / вставить относительно игрока (`-a` — без воздуха) |
| `//rotate` | повернуть буфер на 90° |
| `//undo` | отменить (до 10 шагов) |
| `//count <блок>` | посчитать блоки |
| `//desel` | снять выделение |

Блок с метаданными пишется через двоеточие: `oak_stairs:2`, `oak_log:1`, `torch:3`. Правки работают на любых расстояниях: незагруженные чанки подгружаются (или генерируются) на лету и сразу сохраняются.

## Для съёмки

- **F1** убирает весь интерфейс и руку из кадра.
- **F8** даёт плавную камеру, **C** — плавный зум.
- `/time stop` фиксирует освещение на всю сцену, `/time set sunset` даёт закат.
- **F4** (наблюдатель) и `/speed 0.3` — медленные пролёты сквозь здания; `/speed 5` — быстрые облёты города.
- В настройках *FOV Effects: OFF* отключает «дыхание» FOV при беге и полёте, *View Bobbing* по умолчанию выключен.
- Дальность прорисовки до **64 чанков** (1 км в каждую сторону).
- *Options → Gameplay → Chat Messages: OFF* — сообщения чата не всплывают поверх игры (в окне чата, T, они остаются).

## Запись экрана (Ctrl + F2)

Встроенная запись в MP4 через **ffmpeg**: на видеокартах NVIDIA кодирует чип **NVENC** (почти не нагружает процессор и игру).

1. Скачай ffmpeg для Windows (например, «ffmpeg-release-essentials» с gyan.dev) и положи `ffmpeg.exe` в папку `game` (подходит и `game\ffmpeg\bin\ffmpeg.exe` или ffmpeg в PATH).
2. **Ctrl + F2** — начать / остановить. Видео сохраняются в `game\recordings\`.
3. Настройки: *Esc → Screen Recording...* (или *Options → Gameplay → Screen Recording...*):
   - **Encoder**: NVENC H.264 (по умолчанию), NVENC H.265 (файлы меньше), CPU x264. Если NVENC недоступен, игра сама переключится на другой кодек и напишет об этом.
   - **Resolution**: Window (как окно игры), 720p, 1080p, 1440p, 4K. Масштабирует видеокарта; если форма окна поменялась во время записи, по краям будут чёрные полосы.
   - **Frame Rate**: 24 / 25 / 30 / 50 / 60 / 120. Видео с ровной частотой кадров, даже если FPS игры плавает.
   - **Timing**: *Smooth* (по умолчанию) — пока идёт запись, игра живёт по часам видео: каждый отрисованный кадр — ровно один кадр видео, мир сдвигается ровно на 1/FPS, кадры никогда не выбрасываются (если кодировщик не успевает, игра его ждёт). Движение в видео идеально ровное даже в 120 FPS. VSync на время записи отключается (монитор 60 Гц не тормозит 120-кадровое видео). Если компьютер не тянет нужный FPS, игра во время записи идёт чуть медленнее реального времени, а видео всё равно играет с нормальной скоростью — тогда рядом с REC видно, например, **x0.85**. *Real Time* — как раньше: мир идёт по настоящему времени, кадры повторяются или пропускаются.
   - **Bitrate**: 5–200 Мбит/с (40 Мбит/с для 1080p60 — с запасом).
   - **Pause in Menus**: ON — запись встаёт на паузу, пока открыты служебные меню (Esc, NPC Hub, камера, шейдеры, цветокоррекция, чат, настройки…), и видео склеивается без них. Инвентарь, сундуки, печка, таблички, экран смерти записываются как часть игры. OFF — пишется всё подряд.
- Маленькая метка **REC 00:01:23** (или **PAUSE**) в левом верхнем углу рисуется уже после захвата кадра — в видео её нет.
- Как устроено: видеокарта сама масштабирует кадр и переводит его в YUV 4:2:0 (BT.709), поэтому в ffmpeg уходит в 2,7 раза меньше данных, а ffmpeg ничего не пересчитывает на процессоре (раньше именно его однопоточное преобразование цвета не успевало за 120 FPS и видео дёргалось с любым кодеком). Кадры забираются из видеопамяти в фоне, основной поток их не копирует.

## NPC и актёры (F10)

**NPC Hub** открывается на **F10** (или `/npc`), панель слева. Вкладки в два ряда: верхний — про сцены (**Scenes** — группы-сцены и их NPC, **Play** — проигрывание сцены и что она оставляет в мире, **Record** — как пишутся дубли, **Teams** — фракции), нижний — про выбранного NPC (**NPC** — имя, место, группа, копия, удаление; **Look**; **AI**; **Stats** — скорость, здоровье, урон, физика; **Takes** — запись, дубли, таймлайн). Строка под вкладками показывает, о какой сцене / каком NPC страница. *(1.10)* Пока он открыт, **мир на паузе**, как в меню Esc. На таймлайне мир стоит, пока сцена не играет: нажми *Play*, и она пойдёт. Клавиши `,` и `.` работают и в хабе (для выбранного NPC), и на таймлайне (`.` — *Rec here* с позиции плейхеда). Всё сохраняется в папке мира (`npc\actors.txt`, записи — `npc\recordings\`).

**Обычные NPC**
- *+ New NPC* ставит NPC на блок под прицелом лицом к тебе. ПКМ по любому NPC в мире открывает его настройки.
- **Скин**: Steve (из ресурспака), встроенные образы — Alex, Suit, Worker, Doctor, Police, Red Hoodie, Farmer, Knight, Villain, Kid — и любые свои скины Minecraft: положи `.png` в `game\skins\` (64×64 или старые 64×32, тонкие руки «Alex» определяются сами). Имя файла = имя скина.
- **Поведение**: стоит на месте / смотрит на игрока (поворачивает голову, когда ты рядом) / бродит вокруг места установки / следует за игроком.
- **Поза**: стоит, сидит, крадётся, машет рукой. **Предмет в руке** — тот, что у тебя в руке, кнопкой *Hold*.
- Имя над головой (скрывается вместе с HUD по F1 и за стенами), *Move here*, *Face me*, *Go to*, удаление.

**Запись актёров (как в моде Blockbuster)**
1. *Rec: new NPC* (или *Record* на вкладке *Takes* у выбранного NPC) — обратный отсчёт 3 секунды, и ты играешь роль: ходишь, бегаешь, прыгаешь, крадёшься, летаешь, **садишься, ползёшь, ложишься (Alt + 1..4)**, машешь рукой, меняешь предмет в руке, ставишь и ломаешь блоки, открываешь двери, подбираешь и выбрасываешь предметы, стреляешь, **бьёшь NPC и существ (рукой, предметом, кулаками Alt + Q — стойка и удары тоже пишутся)**, получаешь урон (актёр краснеет). С *+ world* (вкладка *Record*, по умолчанию вкл.) пишется и то, что ты вызвал в мире в 48 блоках вокруг: взрывы, огонь, вода/лава, падающий песок, редстоун. Изменения других актёров и NPC с ИИ в дубль не попадают.
   **Запись от лица NPC** (*Record as the NPC*, вкладка *Record*): ты встаёшь на место NPC, в его скине, играешь, а после дубля возвращаешься туда, где стоял. **F10** — остановить. Реплики в чат по умолчанию не пишутся (озвучка делается на монтаже); при желании их можно включить кнопкой *Chat lines* на вкладке *Scene*.
2. NPC повторяет записанное до тика (20 кадров в секунду), с анимацией шагов и рук.
3. Записываешь следующего актёра — **предыдущие играют вместе с тобой** в тот же момент времени, так можно разыгрывать диалоги и сцены одному.
4. *Play scene* — все дубли вместе с начала. Блоки, которые меняли актёры, перед каждым проигрыванием возвращаются как были и меняются заново, поэтому сцену можно повторять сколько угодно. *To start* — вернуть всё к началу (мир + актёры на метки).
4a. **Воздействие на мир** (*World after the scene*, вкладки *Play* и *Takes*, у каждой сцены своё): **restored** — после каждого проигрывания (и после записи дубля) всё, что актёры сломали, построили, взорвали, подожгли, вернётся как было **до сцены**, вместе с содержимым сундуков, печей, табличек; выпавшие из сундуков предметы убираются. **kept** (по умолчанию) — всё остаётся на местах, но мир до сцены запоминается, и кнопка **Restore world** (в группе, на *Play*, на *Takes*; `/npc restore`) вернёт его в любой момент — если забыл включить. Запомненное хранится в `npc\undo\` и переживает перезапуск игры. `/npc world restore|keep [сцена]` — переключить командой.
5. **Camera path with scene** — путь камеры (F9, клавиши K/L) стартует одновременно со сценой: актёры + пролёт камеры = готовый дубль. Есть повтор (*Loop*), обратный отсчёт 0–5 с, отключение записи блоков и чата.

**Характеристики (вкладка Stats)** — **скорость** 0.25–3×, **HP** до 200, **урон** (0 = от предмета), **частота ударов**, **регенерация** (после 5 с без урона), **Immortal** (ничто не ранит), **Knockback** (отбрасывает ли удар), **Pushable** (расталкивают ли его игрок и другие NPC), **Fall damage**, после смерти — встать дома через 5 с или лежать до *Revive*; *Reset stats*. На вкладке *AI* ещё **Look** (с какого расстояния поворачивает голову к игроку) и **Wander** (радиус прогулок), на *Look* — **цвет имени**. *Duplicate* на вкладке *NPC* — копия NPC со всеми настройками (без дублей).

**Фракции и ИИ (вкладка AI)** *(1.6)*
- **Aggressive** (красное имя) — нападает, как только игрок входит в дистанцию (ползунок *Attack range*, 2–32 блока). Креативного игрока не трогает, если на вкладке *Teams* не включено *Attack creative player*.
- **Neutral** — бьёт только в ответ. *Hit: fights back* — даёт сдачи, *Hit: runs away* — убегает.
- **Friendly** — игрок не может его ударить, и он никак на это не реагирует.
- **Teams** — таблица «кто на кого нападает»: например, агрессивные нападают на нейтральных и дружеских (так по умолчанию), нейтральные на агрессивных и т.д.
- **Защита игрока**: *Guard: defends you* — нападает на того, кто бьёт игрока; *Guard: runs away* — убегает; *ignores* — не реагирует.
- **Следование**: *Follow* — с какой дистанции NPC начинает идти за игроком, *Stop* — на какой дистанции останавливается.
- **Попутчик в машине** *(1.14_61)*: NPC с поведением *Follow player* садится к тебе в машину — подходит к двери свободного пассажирского места, открывает её и садится (дверь закрывается за ним). Пока ты в машине или рядом, он сидит; вышел и отошёл дальше дистанции *Follow* — открывает дверь, выходит и идёт за тобой. В едущую машину не садится, нет мест — просто идёт следом.
- **Tab, глядя на NPC** *(1.14_61)*: NPC в режиме *Follow* **ждёт на месте**, пока ты не вернёшься и снова не нажмёшь Tab, глядя на него (в машине — ждёт в машине). **Tab + 1** — NPC **патрулирует небольшой участок** вокруг себя (4 точки в 3–6 блоках); Tab на нём — возвращается к тому, что делал (снова следует за тобой). Его настоящие точки патруля не теряются. Во время записи Tab + цифра — по-прежнему жесты.
- **Актёры в сцене смертны** *(1.14_61)*: актёра, играющего дубль, можно ранить и убить (выстрел, удар, взрыв; повторённые выстрелы других актёров — при *Replayed hits & shots: damage*). Пока жив — дубль идёт дальше, умер — падает и выходит из дубля. **Водитель убит** — машина остаётся без водителя: дубли пассажиров её больше не двигают, она катится по инерции и останавливается (до следующего запуска сцены).
- **Стрельба из машины** *(1.14_62)*: NPC с оружием в руке, сидящий в машине (попутчик, пассажир или водитель *Drive*), стреляет из окна по своей цели — те же цели, что и пешком (агрессивный — по игроку, *Guard: defends you* — по тем, кто напал на игрока, враждебные фракции, приказ). Голова и оружие поворачиваются к цели, насколько можно с сиденья (цель позади машины — не достать); из едущей машины разброс больше; перезаряжается, когда магазин пуст. Чтобы попутчик защищал тебя из машины, поставь ему *Guard: defends you* (вкладка AI).
- **NPC сцены записываются вместе с дублем** *(1.14_62)*: пока ты записываешь актёра, остальные NPC **этой же сцены (группы)**, живущие по своему ИИ — идущие за тобой (*Follow*), охрана, патруль, водители, — получают **свои дубли** в этой сцене: движение, машина и место в ней, оружие (выстрелы, перезарядки), удары, броски, двери и сломанные блоки. При следующих записях они уже играют свои дубли. NPC других сцен никогда не записываются в эту (попутчик из другой группы — перенеси его в эту группу: вкладка *NPC* → *Scene group*). Выключается на вкладке *Record*: *Scene's NPCs with AI*. Смерть NPC в дубль не пишется: его дубль просто кончается там.
- **Исправлено** *(1.14_62)*: машина с пассажиром-актёром при проигрывании «теряла» скорость (колёса, инерция после конца дубля) — скорость считалась от места, куда её уже поставил дубль пассажира.
- **Посадка и выход актёров** *(1.14_63)*: актёры в дублях садятся в машину и выходят из неё **мгновенно, как игрок** (телепортом в кресло и к двери), без прежней кривой анимации подхода к двери. Дубль кончился, а актёр сидел — он сразу оказывается у своей двери. Исправлено: при повторном запуске сцены машина, переставленная на старт, «сбивала» своего же актёра-водителя и раскидывала тела рядом — перестановка машины сценой больше не считается наездом.
- **Выход из машины** *(1.14_61)*: 1 секунду после выхода ни игрок, ни NPC не получают урона (и толчков).
- **Поиск пути**: NPC обходят стены и препятствия, поднимаются на блок, спрыгивают с небольшой высоты и ищут проход — к цели, к игроку и к стартовой точке сцены.
- **Двери**: NPC открывает деревянные двери и калитки (и закрывает за собой). **Break**: если путь закрыт, ломает блок перед собой (не трогает бедрок и неразрушимые блоки).
- **Здоровье и урон** (0 = по предмету в руке), после смерти — встать через 5 с или лежать, пока не нажмёшь *Revive*. Бить NPC — ЛКМ.

**Группы сцен** *(1.8)*
- Вкладка *List* показывает **группы**. Каждая группа — отдельная сцена со своими NPC и дублями: *+ New group*, дать название (поле сверху + Enter), внутри записывать актёров (*+ Record new*), выйти (*< Groups*), сделать следующую группу и т.д.
- **Copy** — копия группы: те же NPC (на тех же местах, с теми же настройками) **с дублями** (*With takes*) или **без** (*Without*).
- **On / Off** у группы — все её NPC уходят из мира и возвращаются. *Delete* (два нажатия) удаляет группу с её NPC и дублями.
- У каждого NPC: **On / Off** — убрать из мира (он сохраняется, можно включить обратно) и **Scn** — играет ли он в сцене (выключено: сцена идёт без него, а он живёт по своему ИИ). То же на вкладке *Edit* (*In world*, *In scene*) и там же *Group* — перенести NPC в другую группу.
- Старые миры: NPC попадают в группу по названию своей сцены.
- *(1.11)* Дубль всегда принадлежит NPC и его группе: запись (кнопкой, клавишей `.`, на таймлайне) всегда идёт в группу этого NPC, вкладки *Edit/Look/AI* показывают дубль его группы, названия групп не зависят от регистра. Дубль, который в старом мире оказался под чужим названием сцены, при загрузке привязывается обратно к группе NPC.
- Название группы и имя NPC сохраняются и без Enter — достаточно кликнуть в другое место или закрыть хаб.

**Сцены** *(1.6)*
- Сцена группы записывается и играется внутри группы (или вкладка *Scene*, группа выбирается < >).
- Запись больше не сбрасывает NPC: после записи он остаётся обычным NPC со своим ИИ. При *Play scene* каждый актёр **сам идёт к месту, откуда начинается его дубль** (или телепортируется, если выключить *walk to marks*), сцена начинается, когда все на местах, а после своего дубля актёр **снова становится обычным NPC** — со своей фракцией, поведением и т.д. Так ИИ и сцены можно комбинировать: стражник патрулирует, сцена «ограбление» — и он снова стражник.
- Несколько сцен могут идти одновременно.
- *(1.13)* Во время проигрывания на экране нет никаких надписей о сцене (и клавиша `,` запускает её молча) — можно сразу снимать.

**Блок сцены (Scene Block)** *(1.6, 1.8)* — во вкладке *Redstone* креатива. В нём выбирается **группа** (< > или название) и **какие NPC** играют: *All* — все, или отметить одного или нескольких. Если группа выключена, блок её включает (*Wakes group*; можно переключить на *Group as is*). Запуск: *Right click* (ПКМ по блоку), *Player nearby* (игрок вошёл в радиус 1–32 блока), *NPC nearby* *(1.11)* — NPC подошёл к блоку (*Who*: актёры этой сцены, любой NPC или конкретный NPC по имени) или *Lever / button / plate* (рычаг, кнопка или нажимная плита рядом). По умолчанию *Every time* — сцена запускается каждый раз *(1.11)*; *Only once* — один раз, *Re-arm* — снова взвести. Shift + ПКМ — настройки.

**Таймлайн, дубли и позы** *(1.9)*
- **Timeline** (кнопка на вкладке *Edit* или у группы) — панель снизу: у каждого актёра своя дорожка. Полоску дубля можно **перетащить** (начнётся позже) и **обрезать за края**; внизу — **скорость** (0.25–4×), *Offset 0*, **перенос** дубля к тебе (*Move to me*), **поворот** ±15°, *Reset*. Пробел — играть/стоп, стрелки — по кадру, Home — в начало, колёсико — масштаб, линейка — перемотка (NPC сразу встают в кадр, при закрытии всё возвращается).
- **Несколько дублей** у актёра: каждая перезапись — новый дубль (T1, T2…), активный выбирается на *Edit* (< Take 2 / 3 >) или на таймлайне, ненужный удаляется.
- **Rec here** — дозапись с позиции плейхеда (punch-in): всё до этой точки остаётся, дальше ты играешь заново, остальные актёры играют вокруг тебя.
- **Жесты при записи**: **Tab + 1..9** — поза/жест (по умолчанию: руки скрещены, указать, руки вверх, отдать честь, руки в боки, задуматься, facepalm, поклон, сесть на землю), **Tab + 0** — снять. **Alt + 1..7** — эмоция лица (Normal, Happy, Angry, Sad, Surprised, Scared, Eyes closed), Alt + 0 — обычное. Всё пишется в дубль.
- **Ключи поз** на таймлайне: *+ Pose key* — с этого момента актёр плавно переходит в позу; у ключа выбирается **кривая** (Linear, Smooth, Ease in, Ease out, Instant) и **время перехода** (*Blend*). Ключи — ромбики на дорожке, их можно таскать, Del — удалить. Получается анимация поверх записи.
- **Камера на таймлайне**: строка *Camera* — **склейки**: сохранённые кадры (*Save this shot* в F9), *Follow NPC*, *NPC's eyes* (вид от лица), путь камеры или вид игрока. Сцена переключает камеру сама.

**Редактор поз** *(1.9)* — *Look → Pose editor*. Модель игрока (Minecraft/Blockbench: голова, торс, руки, ноги): выбираешь часть и крутишь её ползунками X/Y/Z, торс гнётся в поясе, *Whole* — наклон всей модели (лечь: ±90°), вбок, вверх/вниз. **Хитбокс** (*Box W/H*) у каждой позы свой — сидящий NPC ниже стоящего, по нему и попадают удары/выстрелы. Модель крутится мышью. Встроенные позы (Sit, Kneel, Lie, Dead, Bow, Aim и др. — 22 шт.) меняются только через *Copy*. *Save* — в `game\poses\`, *Key* — назначить на Tab + цифру, *Put on NPC* — поставить в эту позу.

**Внешность (вкладка Look)** *(1.9)* — скин, поза (простые + библиотека), **лицо** (эмоция) и **моргание**, предмет в **правой** и **левой** руке, **броня** (с тебя), **шапка** (предмет из руки, например тыква), *No armor*, **размер** 0.3–3×, имя над головой.

**Поведение (вкладка AI)** *(1.9)* — кроме стоять/смотреть/бродить/следовать: **Patrol** (точки маршрута ставятся там, где ты стоишь: *+ Point here*, по кругу — *Loop* — или туда-обратно), **Seat** (сесть на ступеньку/полублок под прицелом), **Watch** (смотреть на выбранного NPC), **Ride** (сесть на существо или другого NPC).

**Массовка** *(1.9)* — у группы *Crowd...*: N случайных NPC (скины, бродят/патрулируют/стоят) в выделении World Edit или в 14 блоках вокруг тебя.

**Предметы у NPC** *(1.9)* — NPC использует то, что держит: агрессивный с **бомбой** (мод Creatures) при виде игрока бросает её, с рогаткой — стреляет. Работает для любых предметов мода, которые бросают/стреляют снарядами, и для своих (`npcUse` в API — например, огнестрел).

Команды: `/npc spawn [имя]`, `/npc list`, `/npc remove <имя>`, `/npc skin <имя> <скин>`, `/npc faction <имя> aggressive|neutral|friendly`, `/npc record <имя>`, `/npc stop`, `/npc scene <имя сцены>`, `/npc group [имя]` (текущая группа, новая — если нет такой), `/npc groups`, `/npc on|off <NPC или группа>`, `/npc play [сцена]`, `/npc reset [сцена]`, `/npc restore [сцена]` (вернуть мир как до сцены), `/npc world restore|keep [сцена]`, `/npc revive <имя>`, `/npc hub`.

## 3D-модели (F12) *(1.12)*

Свои модели кладутся в папку **`game\3d`** (можно по подпапкам). При первом запуске там появляется `examples` — стол, кепка, часы, лампа, бочка.

**Форматы**
- **Blockbench → File → Export → Java Block/Item Model (.json)**. Текстуры `.png` положи рядом с моделью (имя как в модели, например `"0": "cap"` → `cap.png`); стандартные (`block/stone`) берутся из ресурспака. Повороты элементов, поворот текстур граней, `texture_size` поддерживаются.
- **Blockbench-проект `.bbmodel`** — кубы, mesh-элементы, группы (кости) с поворотами, текстуры прямо из файла.
- **`.obj`** (+ `.mtl`): материалы с текстурой `map_Kd` или цветом `Kd`, прозрачность `d`. 1 единица = 1 блок.

**3D Hub** (**F12** или *Game Menu → 3D Hub*): список моделей, вращаемый просмотр (мышь — повернуть, колёсико — приблизить) с сеткой 1 блок и Стивом для масштаба. Вкладка *Place / size*:
- **Size** (×1/128…×16), *Fit 1 block* / *Fit 2 blocks* (вписать), *x 1/16* (для OBJ в сантиметрах), растяжение по X/Y/Z;
- **Turn X/Y/Z** — поворот модели;
- **Anchor X/Y/Z** — **анкор**: точка модели, которая встаёт на блок или на часть тела (красный крестик). *Bottom / Middle / Top* — низ / центр / верх, *Auto* — низ по центру.
Настройки сохраняются в `game\3d\models.txt` и действуют везде, где модель используется. *Reload* — перечитать файлы после изменений в Blockbench.

**3D-блок** (*3D Block*, вкладка *Decoration* креатива): ставишь — открывается окно (потом ПКМ по блоку). *Model* — какая модель; *Place* — поворот (кнопки ±15°/±90°), наклоны, размер, сдвиг на ±2 блока и **Collision**: ON — игрок, NPC и мобы упираются в габариты модели (модель может быть больше блока, например стол 2×1), OFF — проходят насквозь. Сломать — ЛКМ по самому блоку (нижней клетке).

**Модели на NPC** — *Look → Pose editor → Models*: *+ Add model*, выбрать модель (< >), **часть тела** (голова, тело, руки, ноги — модель двигается вместе с ней в любой позе и анимации), сдвиг X (вправо) / Y (вверх) / Z (вперёд) в пикселях, поворот и размер. Так делаются часы на руке, шапка на голове, рюкзак на спине, оружие в руке. Модели сохраняются у NPC и копируются вместе с группой.

### Кровь, ragdoll, наезд машиной

- **Кровь** от любого урона — пуль, ударов, существ, падений, машин — у NPC, актёров, существ и игрока: брызги летят (от пули — по направлению выстрела из раны), падают и оставляют **пятна** на блоках, на земле — лужи (капли рядом сливаются). Пятна в стиле Minecraft — текстуры 16×16, лежат по пиксельной сетке блока (пиксель крови = пиксель блока): 3 капли и 3 лужи (`blood_0..5.png`, можно подменить в ресурспаке: `assets/minecraft/textures/blocks/`), на стенах подтёки смотрят вниз. Чем больше урон, тем больше крови: удар кулаком — несколько капель, автоматная очередь — брызги, хедшот и падение с высоты — лужа. Свежая кровь ярко-красная, за минуту темнеет, через 5 минут пропадает; пятно исчезает, если блок сломать. Огонь, лава, утопление и голод крови не дают. *Options → Gameplay → Blood* OFF — без крови.
- **Истекать кровью** (**Left Alt + B**, вкл / выкл; клавиша меняется в Controls → «Bleeding on / off»): от первого лица кровь капает из **нижней четверти кадра** тремя ручейками, от третьего и со свободной камеры — из груди. Капли падают на землю и оставляют капли; пока идёшь — на земле остаются **разводы**, стоя на месте — растёт лужа. Выключается тем же сочетанием, при смерти и если Blood выключена в настройках. Кровотечение только визуальное (здоровье не отнимает) и в дубли не записывается.
- **Ragdoll**: убитый NPC или актёр падает как тело — руки, ноги, голова и туловище на шарнирах, по физике: валится от пули назад, от хедшота запрокидывается, перелетает через капот, свешивается с бордюра, сползает по стене, катится со ступеньки; через пару секунд замирает. Скин, броня, предмет или оружие в руке, оружие на спине, подсумки и 3D-модели остаются на теле. Пули, попавшие в лежащее тело, толкают его (и дают кровь), машина тащит его. NPC с включённым возрождением встаёт как раньше. NPC теперь получают урон от падения (как игрок: с 4 блоков).
- **Машины сбивают NPC и актёров**: с 9 км/ч машина уже не отталкивает, а бьёт. Урон от скорости: 30 км/ч — около 12, 50 км/ч — около 23 (насмерть), тело отлетает вперёд по ходу машины и вверх, машина немного теряет скорость. Актёр, сбитый во время сцены, выходит из дубля (дальше его тело живёт по физике). Под машиной уже лежащее тело сдвигается.

## Транспорт *(1.14)*

Машины лежат в папке **`game\transport`**: **одна папка — одна машина**, имя папки — имя машины (`game\transport\nexia\` → `/vehicle nexia`). Добавить или поменять машину можно без компиляции и даже без перезапуска: положи файлы и набери **`/vehicle reload`**. Там же лежат `README.txt` (короткая памятка) и `_template.json` (все настройки).

**Что кладётся в папку машины** (обязательна только модель):
| Файл | Что это |
|---|---|
| `nexia.obj` (+ `nexia.mtl`) | модель OBJ. Части — объекты/группы (`o` / `g`) с именами `wheel1`, `door1`… (см. ниже) |
| `nexia.bbmodel` | проект Blockbench (группы, pivot, текстуры внутри файла) |
| `nexia.json` | модель Blockbench *Export → Java Block/Item Model* (с группами). Тогда настройки кладутся в `vehicle.json` |
| `*.png` | текстуры. Для OBJ ищутся по очереди: `map_Kd` из `.mtl` → `<материал>.png` → `<объект>.png` → `<объект без номера>.png` (`wheel1` → **`wheel.png`**: одна текстура на все колёса) → **`nexia.png`** (общая) → цвет `Kd` из `.mtl`. Так у кузова может быть `nexia.png`, а у колёс — свой `wheel.png` |
| `nexia.json` | **настройки** машины (скопируй `_template.json` и переименуй). Если `nexia.json` — сама модель, настройки — в `vehicle.json` |
| `*.wav` | звуки: `engine.wav` (мотор, крутится по кругу), `idle.wav` (холостой ход), `start.wav` (запуск), `horn.wav` (гудок), `door_open.wav` / `door_close.wav` (или один `door.wav`), `skid.wav` (занос, ручник), `crash.wav` (удар). Находятся по этим именам (можно в подпапке `sounds\`) или по путям из настроек. Формат — PCM `.wav` (8/16 бит, моно или стерео, любая частота) |

**Настройки (`nexia.json`)** — всё необязательно, чего нет — по умолчанию:
| Ключ | По умолч. | Что |
|---|---|---|
| `name` | имя папки | название |
| `maxSpeed` / `reverseSpeed` | 86 / 25 | макс. скорость вперёд / назад, км/ч (1 блок = 1 м) |
| `acceleration` | 23 | разгон, км/ч в секунду (у верха скорости слабеет) |
| `braking` / `handbrake` | 72 / 86 | тормоз (S на ходу) / ручник (пробел), км/ч в секунду |
| `steering` | 32 | угол поворота передних колёс, градусов (на скорости меньше) |
| `stepHeight` | 1.05 | на какую ступеньку заезжает, блоков (проходимость) |
| `weight` | 1200 | вес, кг: тяжёлую машину толкают медленнее, она сильнее бьёт, дольше скользит в дрифте и реже переворачивается *(1.14)* |
| `waterDrag` | 0.85 | какую долю скорости машина сохраняет за тик в воде (1 — вода не тормозит) *(1.14)* |
| `scale`, `turn` | 1, 0 | размер модели и поворот вокруг вертикали (градусов), если перед модели не смотрит в -Z |
| `width`, `height`, `length` | 1, 1, 1 | ширина (x), высота (y) и длина (z) поверх `scale`; места и точки блоков из настроек растут вместе с машиной *(1.14)* |
| `objUnitsPerBlock` | 1 | для OBJ: сколько единиц модели в блоке (модель в сантиметрах — 100) |
| `suspension` | `stiffness` 0.18, `damping` 0.72, `maxPitch` 3.5, `maxRoll` 4, `rideHeight` 0, `heaveLimit` 0.18 | подвеска кузова: жёсткость, гашение, предельные наклоны, высота кузова над колёсами (блоков, минус — ниже), насколько кузов может подпрыгивать |
| `handling` | `grip` 0.5, `driftGrip` 0.04, `driftYaw` 1.6, `driftMinSpeed` 21.6, `policeSpeed` 63, `policeRate` 9, `rollover` 0.033, `rollDamage` 1, `rolloverEnabled` true, `rolloverSpeed` 50, `smashSpeed` 30 | управляемость *(1.14)*: сцепление (как быстро гаснет боковая скорость), сцепление в дрифте, во сколько раз быстрее нос идёт по дуге в дрифте, с какой скорости (км/ч) возможен дрифт и полицейский разворот, наибольший поворот за тик (градусов), **предел боковой силы, при котором машина переворачивается** (0 — никогда) и множитель урона от переворота, `smashSpeed` — скорость (км/ч), с которой машина ломает стекло, доски, листву, заборы и люки, `rolloverEnabled` — переворот вкл / выкл, `rolloverSpeed` — скорость (км/ч), ниже которой машина не переворачивается |
| `open` | `door` 70, `hood` 60, `trunk` 65 | на сколько градусов открываются двери / капот / багажник |
| `parts` | — | по частям: `"door1": { "angle": 80, "pivot": [x, y, z] }` — свой угол (минус — в другую сторону) и pivot. Координаты — в блоках в системе машины: ноль между осями на земле, +x вправо, +y вверх, -z вперёд (их печатает `tools/vehicle_check` и `/vehicle info`) |
| `roles` | — | если часть названа по-своему: `{ "bag": "trunk", "kapot": "hood" }` — группа `bag` будет багажником |
| `seats` | сиденья-группы, а если их нет — 4 возле руля | свои места: `[[-0.54, 0.62, 0.0], [0.54, 0.62, 0.0], ...]` — середина верха подушки в координатах машины; сиденье возле руля — водительское, у каждого своя ближайшая дверь. Порядок в списке — номера мест (не сортируется) |
| `lights` | две фары и два задних огня по размеру модели | **фары** *(1.14)*: `[{"start": [x,y,z], "end": [x,y,z], "width": 3, "intensity": 1, "color": [1,0.95,0.8]}, ...]` — лампа, конец луча, радиус луча в конце, яркость, цвет; ключ есть — заменяет сделанные автоматически (`[]` — без фар) |
| `surfaces` | дорога 1/1, земля 0.9/1, песок 0.75/0.8, снег 0.6/0.85, лёд 0.12/1 | **покрытие** *(1.14)*: `{"ice": {"grip": 0.12, "speed": 1}, "sand": {...}, ...}` — какую долю сцепления и макс. скорости машина сохраняет на дороге (`road`), земле и траве (`dirt`), песке, снегу, льду |
| `blocks` | места `block1`…`block4` модели | **точки крепления блоков** `[[x, y, z], ...]` (до 4): середина низа блока в координатах машины; если ключ есть, они заменяют места из модели (`[]` — ни одного) *(1.14)* |
| `sounds` | `volume` 1, `enginePitchMin` 0.7, `enginePitchMax` 1.8, `gears` 4 | громкость, высота звука мотора на холостых и на макс. скорости, число передач (звук растёт и падает на каждой передаче; 0 — плавно), плюс файлы: `"engine": "v8.wav"` и т. д. |

**Части модели** — по именам групп (Blockbench) или объектов (OBJ), регистр не важен:
- `wheel1`, `wheel2`… — колёса (≥ 2 — это машина); передние (ближе к -Z) поворачивают;
- `door1`…, `hood`, `trunk` (также `bonnet`, `boot`, `hatch`, `lid`) — открываются ЛКМ;
- `steering_wheel` — руль; `seat1`, `seat2`… — сиденья (водитель — ближайшее к рулю, у каждого сиденья своя ближайшая дверь). Нет групп сидений — игра ставит 4 места возле руля (водитель на 0,42 позади руля, пассажир напротив, двое сзади), а `seats` в настройках задаёт их точно;
- `block1`…`block4` — места для блоков (в Blockbench — пустая группа, важен pivot; в OBJ — маленький кубик-метка, он не рисуется, блок встаёт на середину его низа);
- всё остальное — кузов.

Перед машины — **-Z**, верх — +Y, 1 единица = 1 блок (в Blockbench 16 пикселей). В OBJ нет pivot, игра ставит их сама: колёса и руль крутятся вокруг своей середины, двери — вокруг переднего края снаружи, капот — вокруг заднего края, багажник — вокруг переднего (у кромки). Если нужно иначе — `parts.<имя>.pivot` в настройках.

**Как поставить машину**
- Предмет **Car** (творческий инвентарь, вкладка *Transport*): ПКМ по земле. Какую машину ставит предмет — последнюю поставленную, или `/vehicle model <имя>`.
- `/vehicle <имя>` — машина в 4 блоках перед тобой (можно часть имени). `/vehicle models` — все машины из `game\transport` с ошибками и предупреждениями, `/vehicle reload` — перечитать папку, `/vehicle list`, `/vehicle info` (что игра нашла в ближайшей машине), `/vehicle edit` (редактор машин, как Left Alt + End), `/vehicle debug` (насколько дрожит кузов: максимальные изменения за тик), `/vehicle remove` / `/vehicle remove all`.
- Убрать машину: **Shift + ЛКМ** по кузову.

**Управление**
| Клавиша | Действие |
|---|---|
| ПКМ по машине | сесть на ближайшее к месту клика свободное сиденье, **если его дверь открыта** (иначе подсказка «Open the door first»); сиденье у руля — водительское. В машине без дверей садишься сразу |
| W / S | газ / тормоз, на месте S — задний ход |
| A / D | руль (передние колёса и руль в салоне поворачиваются) |
| Пробел | ручник; **с газом и рулём на скорости — дрифт** (следы шин и дым), **на высокой скорости с резким поворотом — полицейский разворот** (раздел «Дрифт…» ниже) |
| Right Alt + F8 | кинематографичные камеры машины: вкл / выкл, Shift — следующий кадр |
| H | гудок (держать; нужен `horn.wav`) |
| Shift | выйти (рядом со своей дверью; если там стена — с другой стороны) |
| ЛКМ по двери, капоту, багажнику | открыть / закрыть (плавно, вокруг pivot группы) — и снаружи, и изнутри. Попадать можно в любое место двери — стекло, рамку, щели: дверь считается целиком, а не только по своим кубам |
| F5 | вид от третьего лица (камера отъезжает дальше, чтобы было видно машину) |

Скорость (до ~86 км/ч, 1 блок = 1 м) видна над хотбаром; подсказка по клавишам показывается 4 секунды после посадки и гаснет. Камера сидит «на подвеске»: с небольшим опозданием повторяет наклоны машины, проседает и подпрыгивает на кочках и ступеньках, при разгоне голову чуть отбрасывает назад, при торможении — вперёд, в поворотах — наружу (прицел качается вместе с камерой). Кузов стоит на подвеске: при разгоне приседает на задние колёса, при торможении клюёт носом, в поворотах кренится наружу, на кочках и ступеньках проседает и мягко покачивается (колёса при этом остаются на земле). Рельеф Minecraft ступенчатый, поэтому колёса видят не «обрыв» в блок, а пологую рампу, а высота и наклон кузова сглаживаются по времени (без отставания на длинном склоне): на скорости 80 км/ч по полю из ступенек машину не трясёт. Машина едет по рельефу: наклоняется на склонах и боком, заезжает на ступеньку в 1 блок, падает с обрыва, упирается в стены выше блока и в другие машины. Игроки и NPC упираются в машину, по ней можно ходить (капот, крыша) и кататься стоя на крыше; стоящих на пути машина расталкивает. Без водителя машина стоит на ручнике. Машины, двери и блоки в кузове сохраняются в `vehicles.txt` в папке мира.

**Блоки в машине.** На место группы `block1` (до 4 мест: `block1`…`block4`) можно поставить блок: возьми блок в руку и наведи на место — появится белая рамка, ПКМ ставит блок так, что середина его низа стоит на pivot группы. Блок ездит вместе с машиной. ЛКМ ломает его (в выживании — с временем добычи, как обычный блок, и с дропом), Shift + ПКМ ставит другой предмет, не используя блок. Блоки с действием работают как в мире — снаружи, на ходу и сидя за рулём: **сундук** (вещи хранятся в машине), **верстак**, **печь** (горит и плавит прямо на ходу), рычаг, люк, блоки модов. Пример: сундук на крыше Жигулей.

**NPC за рулём.** У NPC на вкладке *AI* поведение **Drive a vehicle**: NPC сам идёт к машине, открывает свою дверь, садится, закрывает её за собой и едет. Кнопки: *Car #N* — какая машина (клик — следующая рядом с NPC), *Seat* — водитель или пассажир (2, 3, 4), *Route* — маршрут: клик ставит точку там, где ты стоишь, Shift + клик — очистить. С маршрутом водитель ездит по точкам (по кругу или туда-обратно, как патруль), без маршрута — едет за тобой и останавливается в ~9 блоках (если ты сел к нему в машину — ждёт). Ведёт плавно: газ и тормоз без рывков, в поворотах заранее сбрасывает скорость, руль без «виляния», в конце пути мягко останавливается. Упёршись, сдаёт назад и объезжает. NPC, стоящие на крыше или капоте едущей машины, катаются вместе с ней. API модов: `npcs().setBehavior(имя, "drive")` — сядет в ближайшую машину.

**Машины в сценах.** Записывай дубль, сидя в машине (за рулём или пассажиром): в дубль пишется машина, сиденье, поворот, наклон, руль и открытые двери. При проигрывании NPC садится на то же место, и машина едет точно как в записи (колёса крутятся, руль поворачивается, двери открываются). Можно записать водителя, а потом сесть пассажиром и записать второго актёра поверх — оба поедут в одной машине. Перенос и поворот дубля на таймлайне двигают и машину. После дубля машина остаётся там, где остановилась.

**Редактор машин (Left Alt + End, `/vehicle edit`)** *(1.14)*. Работает так же, как редактор оружия (Alt + Home): панель слева, мир справа не на паузе, **изменения сразу пишутся в файл настроек** (`<имя>.json`, а если `<имя>.json` — модель Blockbench, то в `vehicle.json`; чужие ключи файла — звуки, `roles`, заметки — остаются), перезаходить и набирать `/vehicle reload` не нужно. Редактируется машина, в которой ты сидишь, на которую смотришь, либо ближайшая (до 16 блоков); кнопка `#N next` переключает на следующую. Нет машин рядом — кнопки «Spawn <имя> ahead». Страницы:
- **Speed** — макс. скорость и задний ход (км/ч), разгон, тормоз, ручник (км/ч в секунду), угол руля;
- **Seats** — выбор места (1…8), *Add seat* / *Remove last* / *Mirror*, положение выбранного места X / Y / Z (середина подушки в координатах машины). Места видны в машине зелёными пластинами: оранжевая — водительское, жёлтая — выбранное; **Seat turn (yaw)** — поворот сиденья вокруг вертикали (-180…180°, 0 — лицом вперёд; красный столбик на метке показывает, куда смотрит сидящий): сиденье в багажнике можно повернуть назад или вбок, сидящий смотрит туда (в json — `seatYaw`, по числу на место; pitch и roll нет); кнопка **Camera** — **своя точка камеры** для выбранного места (фиолетовый кубик, ползунки Cam X / Y / Z; камера сидящего встаёт туда независимо от того, как он сидит; в json — `eyes`, по записи на место, `null` — обычное положение над сиденьем); *Seats of the model* возвращает места модели;
- **Blocks** — **точки крепления блоков** (до 4): выбор места, *Add place* / *Remove last*, X / Y / Z (середина низа блока), синий куб — место, голубой — выбранное; *Places of the model* — вернуть из модели;
- **Size** — размер (`scale`) и ширина / высота / длина; машина анализируется заново через долю секунды после последнего движения ползунка, места и точки блоков растут вместе с ней;
- **Suspension** — жёсткость, гашение, наклоны носа и крена, высота кузова над колёсами, предел подпрыгивания;
- **Terrain** (проходимость) — высота ступеньки (оранжевая коробка перед машиной показывает её), доля скорости, сохраняемая в воде;
- **Weight** — вес в кг (на странице видны скорость толкания и устойчивость к опрокидыванию);
- **Handling** — сцепление, дрифт, полицейский разворот, предел переворота и урон от него.
Ползунки: перетаскивание (Shift — точно), ПКМ — значение по умолчанию, Ctrl + клик — ввести число, Ctrl + колёсико — один шаг (Shift — десять), `-` / `+`. Изменённые значения подсвечены, на вкладке страницы стоит `*`. **Ctrl+Z / Ctrl+Y** — отмена / возврат, **Ctrl+S** и *Save* — записать сразу, **Tab** — следующая страница, **Page Up / Down** — предыдущее / следующее место, *Reset page* — страница по умолчанию, *Reload files* — перечитать папку машин. Клавиша открытия — в *Options → Controls* (*Vehicle editor*).

**Двери, капот, багажник в редакторе** *(1.14)*: страница **Doors** — выбор части (голубая коробка), *Open it (test)* / *Open / close all*, **угол открытия** (минус — в другую сторону) и **петля** Hinge X / Y / Z (оранжевый кубик и линия оси); в json — `parts.<имя>.angle` и `.pivot`. *This part as in the model* возвращает как в модели.

**Фары** *(1.14)*. Клавиша **N** в машине (в *Controls* — *Vehicle lights*), NPC-водители включают их ночью. Каждая фара — **точка начала** (лампа) и **точка конца луча** + ширина луча в конце, цвет и яркость; луч — это **динамический свет** вдоль линии от лампы к концу луча: у лампы самый слабый, чем дальше — тем ярче (по трём точкам на луч), останавливается на сплошных блоках (через стекло, траву, заборы проходит); работает при включённом *Dynamic Lights*, ничего не рисует поверх картинки. Без настроек у машины две фары (14 блоков вперёд) и два красных задних огня. Страница **Lights** в редакторе: выбор огня, *Add light* / *Remove*, *Lights on*, Start X/Y/Z, End X/Y/Z, ширина, яркость, цвет; лампа — жёлтый кубик, конец луча — синяя рамка размером с ширину (ширина на свет не влияет, только на метку). Освещение мира динамическим светом не используется.

**Покрытие** *(1.14)*. Блок под машиной — дорога (камень, доски...), земля и трава, песок, снег или лёд — меняет сцепление и скорость: на **льду** при повороте шины сами отпускают, тормозной путь длинный, следов и дыма нет; на песке медленнее, дым цветной. Страница **Surfaces**: сцепление и скорость на каждом покрытии.

**Дрифт, полицейский разворот, переворот** *(1.14)*. Пробел — ручник. На малой скорости или без руля он тормозит, как раньше. **Дрифт**: газ + руль + Пробел на скорости выше `driftMinSpeed` (~22 км/ч) — задние колёса теряют сцепление, нос идёт по дуге быстрее (`driftYaw`), машина скользит боком (боковая скорость `lat` затухает медленно, `driftGrip`); слишком боком — шины снова цепляются. Пока машина скользит, позади колёс остаются **тёмные следы шин** (держатся около двух минут, до 2400 отрезков), из-под колёс идёт **дым**, играется `skid.wav`. **Полицейский разворот**: Пробел + руль на скорости выше `policeSpeed` (63 км/ч) — машину разворачивает почти на 180° примерно за секунду (`policeRate` градусов за тик), она теряет скорость и остаётся ехать задом, дальше — газ. **Переворот**: боковая сила (скорость × угловая скорость поворота при сцеплении плюс скорость, которую шины забирают, когда снова зацепили после заноса) сравнивается с пределом `rollover` × устойчивость (шире, ниже и тяжелее — устойчивее; ниже / уже / легче — менее). Выше предела копится «напряжение», когда оно полное — машина **переворачивается** на 360° за 1,5 с и встаёт на колёса: игрок и NPC внутри получают урон (около 8–10 ХП на 80 км/ч, при старте переворота и ещё немного при приземлении; в творческом режиме без урона), **камера и тело игрока переворачиваются вместе с машиной**, выйти из переворачивающейся машины нельзя. В обычной езде (до ~55 км/ч, короткие повороты) машина не переворачивается; на максимальной скорости долгий полный руль — переворачивает меньше чем за секунду. `rollover` 0 — не переворачивается никогда. Проверка без игры: `sh tools/vehicle_check/handling.sh`.

**Таран** *(1.14)*. Машина быстрее **30 км/ч** (настройка `handling.smashSpeed`, в редакторе *Smash from km/h*) проезжает сквозь **стекло и стеклянные панели, доски, листву, заборы и калитки, люки** и ломает их (с обычными дропами в выживании), теряя понемногу скорость; медленнее — упирается как в стену. Остальные блоки (камень, земля) по-прежнему останавливают.

**Взрыв машины (Ctrl + End, `/vehicle explode`)** *(1.14)*: в машине, на которую смотришь, или рядом (до 8 блоков). Все внутри выбрасываются и получают урон (около 7), рядом всё задевает взрыв (блоки не ломаются). Машина **чернеет**, горит (около 40 секунд, мерцающий оранжевый свет, пламя и искры) и потом **дымит около четырёх минут** (дым редеет); подвижные части — колёса, двери, капот, багажник, руль — **по-разному и немного проворачиваются по своим осям** (колёса разваливаются «домиком», двери и капот висят приоткрытыми); водить и садиться в сгоревшую нельзя. Взорвать **во время переворота** — машина останется там, куда докатилась: на боку, на крыше или встанет на колёса (каждый раз по-разному). `/vehicle repair` — починить. Состояние сохраняется в мире. Ctrl + End — это же клавиша селфи: без машины рядом она работает как селфи.

**Запись в сцены** *(1.14)*: в дубль теперь пишутся и **занос / дрифт** (следы шин и дым при проигрывании), **переворот** (угол), **включённые фары** и **взрыв машины** (при проигрывании машина вспыхивает, чернеет и дымит так же; дубль без взрыва чинит машину, которую взорвал предыдущий дубль). Старые записи читаются как раньше (формат записи — версия 6).

**Столкновения машин** *(1.14)*: машина, врезавшаяся в другую, **толкает** её (тем сильнее, чем тяжелее первая; пустая машина после удара катится без ручника около 1,5 секунды), сама теряет скорость. **NPC и актёры** не получают урона от машин и падений в течение секунд после посадки и высадки (раньше могли погибнуть от «наезда» своей же машины); застрелить, ударить и задавить обычной машиной по-прежнему можно.

**Толкание** *(1.14)*. Подойди к стоящей (без водителя) машине **сзади** (не дальше ~1,3 блока от заднего края, в её ширину) и **держи Alt** (Left Alt, в *Controls* — *Push a vehicle from behind*): игрок встаёт у заднего бампера, **выставляет руки** вперёд (от первого и третьего лица) и медленно толкает машину вперёд, пока держишь. Скорость зависит от веса: обычная машина (1200 кг) — около 3,6 км/ч, лёгкая быстрее, тяжелее ~9000 кг не сдвинуть. Рядом с машиной показывается подсказка «Hold Left Alt: push the car». Не работает с оружием в руке и в режиме боя на кулаках.

**Кинематографичная камера** *(1.14)*. В машине нажми **Right Alt + F8** (в *Controls* — *Vehicle cinematic camera*; F8 — клавиша обычной кинематографичной камеры): камера переходит на **третье лицо и следует за машиной, как в GTA** — висит сзади, сверху, сбоку или спереди, плавно отстаёт на пружине (разворачивается вслед за курсом машины, при разгоне чуть отстаёт, слегка кренится в поворотах и расширяет угол обзора на скорости), не заходит в блоки, игрок виден в машине. Автоматический режим **режет между кадрами каждые 4–8 секунд** (*Chase*, *Far chase*, *Low front*, *Side*, *Helicopter*, *Wheel*; при перевороте сразу общий план). **Shift + Right Alt + F8** — зафиксировать следующий кадр (после последнего — снова автоматический), без Shift — выключить. При выходе из машины камера выключается сама.

**Машины простреливаемые** *(1.14_61)*: пуля проходит через детали машины (искры на входе) и попадает в тех, кто сидит внутри; детали, которые её **останавливают**, выбираются в редакторе машин (Left Alt + End), страница **Bullets**: клик по детали — *passes* / *stops*, *All pass*, *All stop*, *Defaults* (по умолчанию колёса останавливают, остальное пропускает). Красная рамка в машине — деталь, которая останавливает пулю. Пишется в настройки машины (`"parts": {"door2": {"stopsBullets": true}}`). Своя машина стрелка не мешает (стреляешь из окна).

## Огнестрельное оружие

Оружие добавляется как машины: **одна папка в `game\guns\` — одно оружие**, без компиляции. Имя папки — id оружия. Примеры: автомат `game\guns\ak12\` и пистолет `game\guns\fp9\` (каждый появляется один раз — при первом запуске или в первый запуск версии, где он добавлен; удалённый пример не возвращается; звуки свои — положи в папку).

**Что в папке** (на примере `ak12`):
- `ak12.obj` — модель (экспорт OBJ из Blockbench, 1 единица = 1 блок, ствол в сторону −Z). Объекты: части оружия (любые имена), `mag` — магазин, `slide` — затвор. **Служебные** объекты (в игре не рисуются, по ним строятся анимации): `rag` — правая рука на рукоятке, `lag` — левая рука на цевье, `las` — рука на затворе (перезарядка с пустым магазином), `ram` — рука на магазине (старое имя `lam` тоже читается). Какая рука что делает — `magHand` / `boltHand` в JSON или *Arms* в редакторе; по умолчанию как у настоящего АК: магазин меняет **левая**, затвор (он справа) дёргает **правая**. Если `ram` найдена в модели на другом боку магазина, она сама зеркалится на сторону нужной руки. **Рук в модели нет** — руки игровые (скин игрока, обычные майнкрафтовские пропорции), кисти держатся за эти точки; старые объекты `larm` / `rarm`, если есть, не рисуются.
- `ak12.png` — текстура, `ak12_item.png` — иконка в инвентаре, `ak12_mag.png` — иконка магазина.
- `shoot1.ogg` … `shoot3.ogg` — выстрел (каждый раз случайный из тех, что есть; можно `.wav`). Необязательные: `mag_out`, `mag_in`, `bolt`, `dry`, `equip`, `reload` (`.ogg` / `.wav`).
- `ak12.json` — характеристики (всё необязательно, шаблон — `game\guns\_template.json`): `fireRate` (выстрелов в минуту), `mode` (`auto` / `semi`), `magazine`, `damage`, `range`, `reloadTime` / `reloadEmptyTime` (секунды), `moveSpeed` (скорость с оружием в руке), `aimMoveSpeed` (при прицеливании), `sprintSpeed` (во сколько раз медленнее бег с оружием), `spreadHip` / `spreadAim` / `spreadPerShot` / `spreadMove` (разброс в градусах), `recoil` / `recoilSide` (отдача), `aimZoom`, `aimTime`, `firstPersonScale`, **`thirdPersonScale`** (размер в третьем лице), позы от первого лица — у каждой (`hip`, `aim`, `aim2`, `sprint`, `reload`, `bolt`) своё: `<поза>Position` / `<поза>Rotation` (всё вместе: оружие с руками; `hipPosition` — где оружие у бедра), `<поза>GunPosition` / `<поза>GunRotation` (только оружие, руки стоят), `<поза>ArmsPosition` (только руки, оружие стоит), `thirdPersonOffset` / `thirdPersonRotation` (сдвиг и поворот оружия в руках от третьего лица), `aimDistance`, второй прицел (`aim2Distance`, `aim2Zoom`, точка `sight2` в `points`), сила анимаций (`swayAmount`, `bobAmount`, `kickBack`, `kickUp`, `kickRoll`, `sprintTilt`, `reloadTilt`), руки (`armSize`, `armLength`, `armThickness`, `armRightOffset` / `armLeftOffset` — сдвиг руки, `armRightRotation` / `armLeftRotation` — поворот вокруг кисти, `shoulderRight` / `shoulderLeft` — куда рука уходит), `animSpeed` — общий темп анимаций, `poseSmooth` — сглаживание поз бега, перезарядки и затвора: чем дальше поза от обычной (большой поворот или сдвиг), тем дольше и мягче переход в неё и обратно; 0 — без сглаживания, `points` — точки модели вручную (`rag`, `lag`, `las`, `ram`, `sight`, `muzzle`, `magPivot`, `eject`, `boltFront`, `boltBack`), `volume`, трассеры (`tracerChance`, `tracerSpeed`, `tracerLength`, `tracerWidth`, `tracerGlow`, `tracerColor` [r, g, b]), вспышка (`flashOffset` [x, y, z] — сдвиг точки вспышки от дула в единицах модели, `flashSize`), **затвор и перезарядка**: `reloadStyle` (`"rifle"` — магазин выкачивается вперёд, как у АК; `"pistol"` — магазин выскальзывает из рукоятки по своей оси и падает, рука приносит новый и вдвигает снизу, на пустом — передёргивает затвор-кожух сверху), `slideLock` (`true` — после последнего патрона затвор остаётся сзади, как у пистолета, до перезарядки), `boltShot` (на сколько затвор уходит назад при выстреле: доля хода, 1 — до упора). Проще всего всё это настраивать в **редакторе оружия** (ниже).

**Ограничители затвора.** Затвор (`slide`) ходит только по отрезку между точками `boltFront` (точка на затворе в покое; по умолчанию — середина его заднего торца) и `boltBack` (где эта точка, когда затвор отведён до упора). Дальше `boltBack` затвор не уходит ни при выстреле, ни при передёргивании, ни в третьем лице; рука на затворе едет вместе с ним. По умолчанию ход — 90 % длины короткого затвора (рукоятка АК) или 20 % длины длинного (кожух пистолета, больше 40 % длины оружия). Точки двигаются в редакторе: *Points* → `boltFront` / `boltBack` — жёлтый кубик на выбранной точке, голубой на второй и пунктир между ними, затвор показан отведённым (ползунок *Bolt shown at*).

**В игре:** вкладка *Combat* креатива или `/guns give ak12 [магазины]`. **ЛКМ** — стрелять (зажать — очередь), **ПКМ** — прицелиться (зум, меньше разброс, медленнее шаг и мышь), **R** — перезарядка (с оружием в руке R перезаряжает, а не выравнивает горизонт камеры; клавиша — *Options → Controls → Reload gun*). В выживании перезарядка тратит один магазин из инвентаря; в креативе — бесплатно. Патроны хранятся в самом оружии. Справа внизу — патроны и магазины, прицел раскрывается по разбросу, при попадании — хитмаркер.

**Редактор оружия** — **Alt + Home** (или `/guns edit`) с оружием в руке; панель слева, как в NPC Hub, мир справа не на паузе — оружие двигается вживую. Страницы: *Stats* (имя, режим огня, темп, магазин, урон, дальность, время перезарядок, громкость), *Handling* (скорость с оружием, разброс, отдача, зум), *View* — *General* (размер от первого лица; в третьем лице — размер, сдвиг и поворот оружия в руках) и **позы**: *Hip*, *Aim*, *Aim 2*, *Sprint*, *Reload*, *Bolt* — выбранная поза держится на экране, пока её настраиваешь; в позе вкладки *All* (оружие вместе с руками), *Gun* (оружие, руки едут на нём), *Arms* (обе руки поворачиваются вокруг кистей), *R arm* / *L arm* (каждая рука: *Move* — отвести ладонь от точки, *Turn* — повернуть вокруг кисти); сдвиг по XYZ (x вправо, y вверх, z вперёд = минус) и поворот (yaw, pitch, roll); *Anim* (сила качания, шага, отдачи, позы бега, наклона при перезарядке, темп `Anim speed`, `Pose smoothing`; на вкладке *Bolt & style* — стиль перезарядки, затвор сзади на пустом, ход затвора на выстрел, пресеты), *Arms* — *General* (вверху — **выбор руки**: *Mag hand* / *Bolt hand* — *Left* / *Right*, какой рукой менять магазин и дёргать затвор; размер рук, сдвиг и поворот каждой руки, откуда она идёт) и *Hands* (тот же выбор руки вверху — он есть и в позах *Reload* и *Bolt*; **точки касания** кистей `rag` / `lag` / `ram` / `las` — у каждой сдвиг X/Y/Z и поворот кисти yaw/pitch/roll вокруг ладони: на *Grip* / *Guard* — поворот правой / левой руки, на *Mag* / *Bolt* — поворот той руки, что держит магазин / дёргает затвор, только пока она там; в JSON — `magHandRotation` / `boltHandRotation`), *FX* (трассеры; точка вспышки у дула с жёлтым кубиком и размер вспышки; из этой же точки идут дым, свет и трассеры), *Points* (все точки модели кнопками — жёлтый кубик показывает точку на оружии, `*` — задана вручную, клик по названию — вернуть найденную в модели; там же ограничители затвора). Кнопки внизу проверяют анимации без патронов: *Shoot*, *Burst*, *Reload*, *Empty* (с затвором), *Aim*, *Walk*, *Run*, *Equip*, вид 1-го / 3-го лица, *Speed* (замедление), *Undo* / *Redo*, *Reload files*, *Save*. **Изменения сразу пишутся в `ak12.json`**, перезаходить не нужно.

**Удобства редактора:**
- Каждая страница и каждая поза разбиты на **вкладки**, чтобы всё помещалось без прокрутки: в позе — *All* (оружие с руками), *Gun* (оружие, руки едут на нём), *Arms* (обе руки поворачиваются вокруг кистей), *R arm* / *L arm*; на *Handling* — *Moving / Spread / Recoil & aim*; на *Anim* — *Motion / Bolt & style*; на *FX* — *Tracers / Flash*; на *Arms* — *General* (*Size / R arm / L arm*) и *Hands* (какая рука меняет магазин и дёргает затвор, точки касания *Grip / Guard / Mag / Bolt*). Звёздочка `*` на вкладке или позе — там есть значения не по умолчанию; изменённые ползунки подсвечены голубым.
- **Отмена и повтор**: *Undo* / *Redo* или **Ctrl+Z** / **Ctrl+Y** (Ctrl+Shift+Z) — для любого изменения, до 200 шагов на каждое оружие; перетаскивание ползунка — один шаг.
- **Точный ввод**: **Ctrl + клик** по ползунку — ввести число (Enter — применить, Esc — отмена); **Shift + перетаскивание** — в 10 раз точнее; **Ctrl + колесо** над ползунком — шаг (с Shift — 10 шагов); `-` / `+` с Shift — 10 шагов; правый клик — по умолчанию.
- **Позы**: *Copy pose* / *Paste pose* (**Ctrl+C** / **Ctrl+V**) — скопировать всю позу в другую или в другое оружие; *Reset tab* — вернуть вкладку к умолчаниям. В *Reload* и *Bolt* ползунок **Hold at** — в какой момент перезарядки (или передёргивания затвора) поза держится на экране, можно прокрутить всю анимацию по кадрам.
- **Замедление**: кнопка *Speed* — 1x, 1/2, 1/4, 1/10 (анимации, перезарядки и очереди в редакторе), чтобы разглядеть движение.
- **Пресеты** (*Anim → Bolt & style*): *Rifle poses* / *Pistol poses* — позы, стиль перезарядки, руки и затвор автомата (как по умолчанию) или пистолета (как у FP9); размеры и точки не трогаются, отменяется Ctrl+Z.
- Клавиши: **Пробел** — выстрел (Shift — очередь), **R** — перезарядка (Shift+R — с пустым магазином), **Tab** / Shift+Tab — страницы, **PageUp / PageDown** — позы, **Ctrl+S** — сохранить.

**Руки всегда на оружии.** Ладони держатся за свои точки на *нарисованном* оружии во всех позах: сдвиг и поворот *Gun* в позе (например, наклон оружия к затвору в *Bolt*) уносит руки вместе с оружием, а *Arms* поворачивает обе руки вокруг кистей (меняет, откуда они идут), не отрывая ладоней. Отвести ладонь от точки нарочно можно только *R arm* / *L arm → Move* (и *Arms → General*).

**Второй прицел (Aim 2):** в прицеле зажми **Alt** (или зажми Alt, потом ПКМ) — оружие плавно переходит во вторую позу прицеливания, отпустил — обратно. Так делаются угловой (наклонённый) прицел, боковой коллиматор, переключение на другой прицел или увеличитель. У второго прицела своя точка `sight2` (вкладка *Points*, по умолчанию — как `sight`), своя дистанция, свой зум и поза (*View → Aim 2*: наклон по умолчанию 35°). Оба прицела ставят свою точку точно в центр экрана, а поворот позы идёт вокруг неё — точка не уезжает. Клавиша — *Options → Controls → Second aim*.

**NPC с оружием.** Дай любому NPC оружие в руку (*NPC Hub → Look*, предмет из вкладки *Combat*) — в бою он стреляет сам, не только актёры в сценах. Кто воюет, решает обычный ИИ (*AI*: агрессивный нападает на игрока, охранник защищает, нейтральный отвечает на попадание, фракции на *Teams*). С оружием NPC держит дистанцию (подходит, если цель далеко или за укрытием, отступает, если совсем рядом), целится в грудь, сначала полсекунды прицеливается, потом стреляет короткими очередями по 2–5 выстрелов с паузами 0.6–1.5 с (полуавтомат — одиночными с паузами), когда видит цель и развернулся к ней, с разбросом оружия (больше на ходу и вдали). Магазин кончился — перезаряжается (анимация и звуки, между боями дозаряжается сам). Пули настоящие: попадают в игрока, других NPC (те отвечают) и мобов, бьют блоки, с трассерами, вспышкой света и дымом у дула; выстрел слышно по месту — тише вдали, слева или справа.

**Выстрелы в дублях.** Пока записываешь дубль, каждый выстрел (с точным направлением и разбросом) и перезарядка пишутся в него; при проигрывании актёр стреляет так же — вспышка, трассер, звук, попадания с искрами и кровью, перезарядка с анимацией. Сдвинутый и повёрнутый на таймлайне дубль стреляет в повёрнутую сторону. *NPC Hub → Scene → Gun shots in takes*: **hits only** (по умолчанию — пули видно, но урона нет, сцену можно гонять сколько угодно) или **damage** (актёры по-настоящему ранят и убивают).

**Дырки от пуль.** Куда попала пуля — на грани блока остаётся тёмная дырка с опалённым краем (от любого стрелка: игрок, NPC, дубли, предпросмотр в редакторе). Держатся 2 минуты, последние 20 секунд тают; пропадают сразу, если блок сломан или изменился; одновременно — до 600 (старые уходят первыми).

**Двери.** Деревянная дверь от твоих пуль трескается с каждым попаданием (трещины как при добыче блока, на обеих половинах, и щепки) и разлетается, когда урон пуль наберёт **30** (обе половины, ничего не выпадает): AK-12 (урон 7) — с 5-го выстрела, FP9 (урон 5) — с 6-го, мощное оружие быстрее; если 10 секунд по ней не стрелять, трещины пропадают. Удар прикладом — 10 урона (дверь ломается с трёх ударов).

**Факелы.** Пуля сбивает факел (и красный факел, и факелы модов): он разлетается частицами и гаснет, в выживании выпадает предметом. Как и стекло с дверями — от твоих выстрелов и в дублях; пули NPC в бою факелы не трогают. Железные двери пули не берут (только дырки). Пули NPC в бою двери и стекло не трогают, чтобы бой не ломал постройки; то, что сломал или открыл ты во время записи, попадает в дубль как изменение блоков, а выстрелы актёра при проигрывании дубля трескают дверь так же, как при записи.

**От третьего лица** оружие дёргается при каждом выстреле (назад и вверх), при перезарядке задирается и наклоняется, рука вынимает магазин и вставляет новый, на пустом магазине другая дёргает затвор (руки — как в настройках оружия) — у игрока и у NPC.

**Перезагрузка без перезахода:** `/guns reload` (или *Reload files* в редакторе) перечитывает всё: новые папки (их предметы появляются сразу), модели и текстуры, иконки, звуки, JSON. Кроме того, игра сама замечает изменённые файлы в `game\guns\` (в течение секунды) — достаточно сохранить модель в Blockbench или текстуру. Отключить — `/guns auto off`. Команды `/gun …` и `/guns …` одинаковые.

**Пистолет (FP9, `reloadStyle: "pistol"`)**: держится двумя руками (левая обхватывает правую на рукоятке), отдача и затвор-кожух на каждом выстреле уходит назад до упора (`boltShot` 1), после последнего патрона кожух остаётся сзади (`slideLock`). Перезарядка: пистолет поворачивается рукояткой к левой руке, которая сразу уходит к карману; магазин плавно выскальзывает из рукоятки по своей оси (ось находится сама по наклону магазина в модели), всё быстрее, и, отпущенный, продолжает падать в кадре с той же скоростью, кувыркаясь, пока не уйдёт вниз (так же теперь падает и отпущенный магазин автомата, а не исчезает), а в мире падает на землю; рука приносит новый, подводит под рукоятку и вдвигает до щелчка. На пустом магазине левая рука сверху берёт кожух сзади (`las`), отводит до `boltBack` и отпускает. Те же моменты событий, что у автомата (звуки, выпавший магазин, третье лицо, NPC).

**Анимации** (от первого лица, как в современных шутерах, в темпе Minecraft — `animSpeed`): **руки — игровые майнкрафтовские** (скин игрока, без растягивания), кисти всегда на точках модели (`rag` — рукоятка, `lag` — цевьё, `ram` — магазин, `las` — затвор) и едут за ними во всех анимациях, рука при этом сохраняет наклон и не разворачивается в камеру; каждую руку можно сдвинуть и повернуть в редакторе. Слои на пружинах (с весом и перехлёстом): качание за мышью, наклон при шаге вбок, покачивание восьмёркой в такт шагам, всплытие в прыжке и просадка при приземлении, резкая отдача (назад, вверх, случайный поворот и крен), дыхание, поза бега (оружие наклонено и развёрнуто), доставание с перехлёстом. Перезарядка по ключевым кадрам с пружиной поверх: оружие поднимается и разворачивается приёмником к игроку, рука берёт магазин (по умолчанию левая), выкачивает его вперёд, тянет вниз и **отпускает — старый магазин падает на землю** (кувыркается, отскакивает и минуту лежит на боку; видно со стороны, у NPC тоже), рука уходит к карману, **достаёт новый** и несёт его в руке к оружию, цепляет передом и докачивает назад со щелчком; на пустом магазине оружие поворачивается боком к затвору, рука (по умолчанию правая) тянется к нему, оттягивает и отпускает (затвор досылается рывком). Затвор ходит на каждом выстреле, из окна вылетают гильзы. От третьего лица игрок (и NPC с оружием в руке) держит оружие в обеих руках чуть правее середины груди: правая кисть на рукоятке, левая на цевье, корпус чуть развёрнут левым плечом вперёд, а тело с оружием в руках всегда разворачивается туда, куда смотрит голова (и при ходьбе боком или назад — руки не отрываются от оружия), а оружие и обе руки смотрят туда же, куда голова (вверх-вниз и в стороны). Подогнать — *View → General*: размер, сдвиг и поворот в третьем лице; проверить — кнопка вида в редакторе.

**Проверка без игры (для Claude):** `sh tools/gun_check/check.sh <папка>` — части, точки, звуки, руки (не растягиваются, кисти на точках), перезарядки, хват от третьего лица; `sh tools/gun_check/preview.sh <папка>` — картинки поз от первого и третьего лица (`/tmp/gun_preview/sheet.png`, `3p/sheet.png`); `sh tools/gun_check/tests.sh <папка>` — тесты с числами. Описание — `tools/gun_check/README.md`.

Пули: мгновенные лучи до `range`, попадают в блоки (осколки и искры, стекло бьётся), существ и NPC. **Трассеры** — у любого оружия случайные пули (по умолчанию примерно каждая третья, `tracerChance` 0.3) летят видимой жёлтой светящейся полосой от дула до точки попадания: длинная (5 блоков), быстрая (320 блоков/с), с ярким ядром и мягким ореолом (со включённой пост-обработкой даёт свечение bloom), голова трассера подсвечивает всё вокруг (если включены динамические источники света). Видны с любой камеры, в том числе от третьего лица; на паузе замирают в воздухе. Всё настраивается на вкладке *FX* редактора. `/guns list` — оружие и найденные ошибки, `/guns reload` — перечитать всё.

### Удар прикладом (СКМ с оружием в руке)

С оружием в руке **СКМ** (колёсико) — удар прикладом, у пистолета — рукояткой. Три вида, у каждого свои позы, время и урон:
- **Jab** — замах вправо назад, оружие разворачивается поперёк и приклад выбрасывается вперёд к прицелу (у пистолета — удар наотмашь влево, левая рука отпускает);
- **Swing** — замах вправо, приклад проходит дугой справа налево (у пистолета — обратный удар вправо);
- **Smash** — приклад поднимается вверх и рубит вниз вперёд (у пистолета — рукояткой сверху вниз, как молотком).

**Связка:** нажми ещё раз, пока оружие возвращается (или в течение `meleeCombo` секунд после удара) — следующий вид: Jab → Swing → Smash → снова Jab. Первый удар после паузы — всегда Jab.

Удар разгоняется к концу и бьёт в момент полного вылета то, что под прицелом в пределах `meleeReach` (2,6 блока у автомата, 2,2 у пистолета): существа (с отбрасыванием `meleeKnockback`) и NPC — урон своего вида (у AK-12: 4 / 5 / 7, у FP9: 3 / 3,5 / 5), в падении в полтора раза больше; стекло бьётся, деревянная дверь трескается (удар = 3 пули). При попадании оружие отскакивает назад и на миг замирает (стоп-кадр), мимо — проходит чуть дальше. Во время удара нельзя стрелять и целиться; во время перезарядки удар не начинается.

От третьего лица (и у актёров в дублях) игрок делает тот же удар — те же позы, только оружие у груди. Пока пишется дубль, удар пишется в него (вид удара) и при проигрывании актёр его повторяет; урон во время записи не наносится, как и у кулаков. Что удар сломал (стекло, дверь), попадает в дубль как изменение блоков.

**Звуки** (необязательно): в папке оружия `melee.ogg` (замах) и `melee_hit.ogg` (попадание), можно `.wav`; если их нет — берутся звуки кулаков из `game\fists\` (`swing*`, `hit*`).

**В редакторе оружия** (**Alt + Home**): *View → Melee*. Сверху — вид удара (**Jab / Swing / Smash**) и **Setup**; у вида — **Wind-up** (поза замаха), **Hit** (поза удара), **Timing** (время замаха, самого удара, задержки и возврата в секундах, урон) и кнопка **Play**. Позы правятся теми же вкладками, что и остальные (*All / Gun / Arms / R arm / L arm*, Copy / Paste / Reset tab), **Hold at** — в какой момент удара он стоит на экране (сначала — конец замаха или момент удара). *Setup*: дальность, отбрасывание, окно связки и кнопки проверки каждого вида и всей связки (*Combo*). Клавиша удара в редакторе тоже проигрывает удар; *Speed* замедляет. Пресеты *Rifle poses* / *Pistol poses* ставят и удары. В JSON — ключи `jabWindPosition`, `jabHitRotation`, `swingHitGunRotation`, `smashHitLeftArmPosition`… (как у остальных поз), `jabWindTime` / `jabStrikeTime` / `jabHoldTime` / `jabBackTime`, `jabDamage` (и так же `swing…`, `smash…`), `meleeReach`, `meleeKnockback`, `meleeCombo`. У пистолета без этих ключей в JSON (например, старый `fp9.json`) удары сами берутся пистолетные.

Клавиша переназначается: *Options → Controls → Gun melee*.

### Снаряжение: подсумки для магазинов (Left Alt + E)

**Left Alt + E** открывает снаряжение: посередине игрок, слева **3 подсумка** левой стороны пояса, справа **3 подсумка** правой, внизу инвентарь. В подсумки кладутся **только магазины** оружия, **не больше 3** в каждый (18 всего). Перетаскивание и Shift-клик работают как в сундуке (Shift-клик по магазину в инвентаре кладёт его в подсумок, по подсумку — обратно).

- **Перезарядка** (R) берёт магазин **сначала из подсумков**, потом из инвентаря. На экране патронов видно, сколько магазинов в подсумках.
- От третьего лица магазины видны на поясе спереди: левые подсумки слева от пряжки, правые справа.
- Подсумки сохраняются вместе с миром, при смерти в выживании магазины выпадают.
- Клавиша: *Options → Controls → Equipment (magazine pouches)*. Обычная **E** — инвентарь, как раньше.
- **Где магазин сидит в подсумке** настраивается для каждого типа магазина: возьми магазин в руку и нажми **Left Alt + Home** (тот же редактор оружия, но в режиме «Magazine mount»). Магазин показывается сразу во всех шести подсумках, вид автоматически «3rd front». Ползунки: сдвиг (наружу от середины пояса / вверх / вперёд), поворот вокруг середины магазина (yaw / pitch / roll) и размер. Правые подсумки зеркальны левым. Значения лежат в json оружия (`pouchOffset`, `pouchRotation`, `pouchScale`) и работают для всех магазинов, в том числе у актёров.
- **Актёры и NPC**: при записи дубля в кадр пишутся магазины в подсумках игрока (формат записи v5, старые записи читаются), актёр носит их при воспроизведении сцены; если во время дубля игрок перезаряжался, магазинов в подсумках на сцене тоже становится меньше.

### Попадания: хедшоты, блоки, камеры

- **Хедшот**: попадание в голову (верхняя четверть тела у NPC, существ и игрока) наносит урон × `headshotMultiplier` (по умолчанию **2,5**: AK-12 — 17,5, т. е. почти всегда насмерть), крови больше, у прицела вспыхивает **красный крест**. Звук хедшота — `headshot.ogg` / `.wav` в папке оружия (необязательно). Множитель — в редакторе оружия (*Stats → Headshot x damage*) или в JSON.
- **Пули выбивают куски из блоков**: на каждом попадании — выщербина (растёт с каждым выстрелом в тот же блок), разлетаются куски этого блока, по блоку идут трещины. Когда урон наберёт прочность блока, он **разваливается** (ничего не выпадает): прочность = 6 + 30 × твёрдость: земля и песок — 3 выстрела AK-12, камень — 8, доски и булыжник — 10, листва и трава — 1–2, обсидиан почти не берётся; бедрок, жидкости и блоки с содержимым (сундуки, печи, таблички, 3D-модели) не ломаются — только трещины. Если минуту не стрелять, трещины пропадают. *Options → Gameplay → Bullets Break Blocks* OFF — блоки только щербятся и трескаются, не разваливаются. Ломают блоки выстрелы игрока; выстрелы NPC в бою и дубли — только щербины (в дубле блок ломается записанным изменением блока). Мод может задать прочность своему блоку: `BlockBuilder.bulletHealth(урон)` (0 — пули его не ломают).
- **Камеры наблюдения разбиваются** с первой пули (искры, осколки; камера пропадает из списка экранов). Это работает и для **любых будущих камер** без правки кода: камерой считается блок, у которого блок-сущность — камера (`CameraEntity` или её наследник), блок `CameraBlock` (и наследники) или блок, в имени которого есть «camera».

### Оружие на спине (Left Alt + F)

С оружием в руке **Left Alt + F** — оружие уходит **за спину**: от первого лица оно опускается вниз из кадра, слот хотбара пустеет, а от третьего лица (и в тени) оружие висит на спине. **Автомат** — наискось через спину на боку: ствол вверх над правым плечом, приклад у левого бедра; **пистолет** (`reloadStyle: "pistol"`) — за поясом сзади: ствол влево, рукоятка вверх справа. Слева от хотбара появляется слот с оружием на спине (как слот второй руки в новых версиях). С пустыми руками можно делать что угодно: ставить блоки, драться на кулаках (Alt + Q), брать другие предметы.

Ещё раз **Left Alt + F** — правая рука тянется за спину (за плечо у автомата, к поясу у пистолета), и оружие возвращается **в тот же слот**, слот выбирается, оружие поднимается в руки снизу. Если в этом слоте за это время что-то появилось, оно переезжает в свободный слот (если свободных нет — оружие остаётся на спине, в чате об этом сказано). Если в руке другое оружие, они меняются местами: то, что в руке, уходит на спину.

- Оружие на спине сохраняется вместе с миром; патроны в нём остаются как были. Если игрок умирает в выживании, оно выпадает вместе с остальным инвентарём.
- Пока пишется дубль, оружие на спине и рука, тянущаяся за ним, пишутся тоже: актёр в сцене носит оружие на спине и достаёт его в тот же момент (старые дубли читаются как раньше).
- Подогнать положение на спине: редактор оружия (**Alt + Home**) открывается и с оружием на спине, *View → General → 3rd person*: **On the back: size** (размер на спине, отдельно от размера в руках; 0 — как *3rd person size*), **On the back: move** (сдвиг, блоки) и **On the back: turn** (поворот вокруг середины оружия); смотреть от третьего лица (F5). В JSON — `thirdPersonBackScale`, `thirdPersonBackOffset`, `thirdPersonBackRotation`.
- Клавиша переназначается: *Options → Controls → Gun on the back / in the hand*. Обычная **F** (фокус камеры) по-прежнему работает без Alt.

### Бой на кулаках (Left Alt + Q)

**Left Alt + Q** включает и выключает бой от первого лица. Руки — те же игровые руки со скином игрока, что держат оружие (жёсткие майнкрафтовские, не растягиваются), и анимации того же уровня: кулаки поднимаются снизу в боксёрскую стойку (левый впереди), стойка качается за мышью с инерцией, наклоняется при шаге вбок, покачивается восьмёркой в такт шагам, всплывает в прыжке и проседает при приземлении, «дышит»; на бегу кулаки опускаются и работают в такт шагам.

- **ЛКМ — удар левой, ПКМ — удар правой.** Удар: короткий замах, резкий выброс к прицелу с поворотом кулака (штопором), миг на полном вылете, возврат в стойку. Корпус доворачивается в удар (плечо вперёд), второй кулак прижимается к подбородку.
- **Связка**: та же рука ещё раз сразу после удара — **боковой (хук)**: по дуге сбоку, локоть вверх, кулак ладонью вниз; потом снова прямой. Зажатая кнопка — удары один за другим (прямой, хук, прямой...). Руки бьют независимо: левой-правой можно чередовать сколько угодно быстро.
- **Попадание**: удар бьёт то, что под прицелом в момент полного вылета (существа и NPC — до 3,5 блока): прямой — 2 урона, хук — 3, в падении — в полтора раза больше (крит), удар на бегу отбрасывает сильнее, хук — вбок. Попавший кулак отскакивает на пружине, стойку встряхивает, и на долю секунды движение замирает (хит-стоп) — удар ощущается. По блоку — глухой удар с крошкой, блок не ломается. Пока пишется дубль, удары видны, но не ранят (как и обычные удары).
- В режиме кулаков мышь не ломает, не ставит и не использует предметы (предмет в руке не показывается); машины работают как обычно (двери, сесть). С оружием в руке, в машине и в режиме наблюдателя кулаки опускаются, а режим остаётся включённым.
- От третьего лица (и в дублях) игрок держит стойку: руки вперёд перед лицом, удар — рука прямо туда, куда смотрит голова, корпус доворачивается.
- **Звуки** (необязательно): положи в `game\fists\` файлы `swing1..3` (замах) и `hit1..3` (попадание), `.ogg` или `.wav` (можно и просто `swing` / `hit`).
- Клавиша переназначается: *Options → Controls → Fist fighting on / off*.

## Скин игрока (Left Alt + F9)

**Left Alt + F9** открывает выбор скина игрока: тот же список, что у NPC — Steve (из ресурспака), встроенные образы (Alex, Suit, Worker, Doctor, Police, Red Hoodie, Farmer, Knight, Villain, Kid) и все `.png` из `game\skins\` (64×64 или старые 64×32; тонкие руки «Alex» определяются сами).

- Слева список с лицами и поиском, справа — большая картинка скина спереди и сзади (того, что под мышью, иначе надетого). **Клик — надеть сразу**, мир за меню не на паузе.
- Скин носит всё: модель игрока от третьего лица и спереди, тень, селфи, **руку от первого лица**, **руки, которые держат оружие**, и **кулаки** (Alt + Q) — со вторым слоем (рукава) и тонкими руками у «slim»-скинов.
- Кнопки: вид 1-е / 3-е лицо / спереди (посмотреть скин на модели), *Open skins folder* (папка `game\skins\` — положи туда PNG), *Reload list*, *Done*.
- Выбор хранится в `game\options.txt` (`playerSkin`) и один для всех миров. Если файл скина удалили — снова Steve. Клавиша — *Options → Controls → Player skin*.

## Камеры видеонаблюдения и экраны

Камера снимает мир, а **экран-холст** показывает её картинку. Так делаются видеонаблюдение, мониторы охраны, телевизоры, «камкордер» на штативе.

**Камера** (*Security Camera*, вкладка *Redstone*; крафт: железо по краям, в центре стекло и редстоун — `iii / igr / iii`). Модель — `security_camera.bbmodel`, она же лежит в `game\3d\examples\`. Ставится на любое место и сразу смотрит на тебя; открывается меню, где вводится **код** (пароль), по нему к камере подключаются экраны. Без кода камеру не подключить. Повторный ПКМ по камере сначала спрашивает код, потом открывает настройки:
- *Name* — имя (видно в меню экрана после подключения), *Code* — код (*Show* — показать звёздочки);
- *Turn* / *Tilt down* — куда смотрит (поворот и наклон), *Field of view* — угол обзора (зум), *Range* — дальность (16–256 блоков, но не дальше дальности прорисовки);
- *Aim where I look* — направить камеру туда, куда смотришь ты;
- *Quality* — Low 192×108, Medium 320×180, High 640×360; *Night vision* — ночное видение (светлее, зеленоватая картинка); *Camera: ON/OFF*;
- внизу — живая картинка камеры.

**Экран-холст** (*Screen Canvas*, вкладка *Redstone*; крафт: 8 стеклянных панелей вокруг редстоуна — 2 холста). Вешается на любую грань любого блока, как рамка, в том числе на **3D-блок** (на него — **Shift + ПКМ**, иначе откроется меню 3D-блока). Меню (ПКМ по холсту) в стиле хабов, мир справа виден, всё меняется сразу:
- *Camera* — ввести код камеры и *Connect* (*Disconnect* — отключить), яркость. Если камеры с таким кодом нет рядом, код всё равно сохраняется — картинка появится, когда камера загрузится;
- *Size* — ширина и высота (до 8 блоков), *Height = 16:9*, сдвиг вправо / вверх / от стены (±4 блока), поворот в плоскости (*Turn*, ±90°), для холста на полу или потолке — *Top side* (где верх картинки);
- *Crop* — обрезать картинку с каждой стороны (до 45%); *Crop to fill* — обрезать так, чтобы картинка заполнила холст без растяжения.

Без сигнала экран тёмно-синий, у выключенной камеры — чёрный, сзади холст тёмный. Ползунки сбрасываются правой кнопкой.

**Как сделать монитор.** Поставь 3D-блок с моделью `examples/monitor.bbmodel`, повернувшись к месту, откуда будешь смотреть. Shift + ПКМ по передней грани 3D-блока — повесь холст, открой *Size*: ширина 1,38, высота 0,78 (экран модели 22×12,4 пикселя), *Move out* −0,36 (холст уходит внутрь клетки 3D-блока, к экрану модели), *Move up* 0,19 — для 3D-блока без сдвига, размера и поворота. Для моделей из модов — так же: подгони размер, сдвиг и обрезку под рамку экрана.

Как это работает: каждый кадр обновляются только камеры, чьи экраны сейчас видны (не больше двух камер за кадр, каждая — не чаще чем раз в два кадра). Картинка камеры — рельеф, небо, существа, NPC, машины и игрок, без теней, облаков и пост-эффектов. Экран, который показывает ту же камеру, в её собственной картинке тёмный (без бесконечного «зеркала»).

## Камера (F9)

Панель **F9** открывается слева, мир продолжает работать и всё видно сразу. Настройки камеры сохраняются в `game\camera.txt`, путь камеры — в папке мира (`camera_path.txt`).

**Режимы**
- **Свободная камера (V)** — камера отрывается от игрока: WASD, Пробел/Shift — вверх/вниз, Ctrl — ×3, колёсико — скорость. Разгон и торможение плавные (*Smoothing*). Игрок остаётся стоять и виден в кадре.
- **Орбита (O)** — облёт вокруг блока в центре экрана; **Shift+O** — вокруг игрока (центр следует за ним). W/S — радиус, A/D — скорость и направление, Пробел/Shift — высота.
- **Штатив (P)** — в свободной камере или орбите: камера остаётся на месте (орбита продолжает вращаться), а клавиатура и мышь снова управляют игроком. Так можно снимать самого себя.
- **Пути камеры** — ставь ключевые кадры **K** (запоминаются позиция, направление, наклон, фокусное расстояние и фокус), **L** — проиграть. Камера идёт по гладкой кривой (Catmull-Rom) через все кадры, с равномерной скоростью или «как расставлены» ключи, с плавным стартом/остановкой (*Ease*: Linear, Smooth, Ease In, Ease Out), длительность 1–120 с, повтор (*Loop*). Кривая и ключи видны в мире жёлтой линией (выключаются, когда скрыт HUD). Во время проигрывания можно управлять игроком — играть сцену, пока камера едет.

**Объектив**
- Фокусное расстояние **8–300 мм** (сенсор 24 мм по высоте, как Super 35): 8–16 мм — сверхширокий, 24–35 — широкий, 50 — нормальный, 85–135 — портретный, 200–300 — телевик. На длинных объективах мышь замедляется, чтобы было удобно кадрировать.
- **Наклон горизонта** (голландский угол) — Z/X или ползунок, плавно.
- **Анаморфот 1–2×**: овальное (вытянутое вертикально) боке и горизонтальные блики. **Letterbox** 2.39:1 / 2:1 / 1.85:1 / 4:3.
- Дисторсия (бочка/подушка), хроматическая аберрация, «ручная» тряска камеры с регулировкой силы и частоты.

**Фокус**
- **Глубина резкости** по формуле тонкой линзы: зависит от фокусного расстояния, диафрагмы (f/0.95–f/22) и дистанции, как у настоящей камеры. Боке собирается по золотому углу, резкий объект не «размывается» задним планом. Рука в кадре не размывается.
- **Автофокус**: *Center* — по центру кадра, *Player* — на игрока (в третьем лице, свободной камере, орбите), *Manual* — вручную. **AF Speed** — скорость перевода фокуса (маленькие значения — медленный киношный перевод).
- **F** — зафиксировать фокус на том, что под прицелом; **Shift+F** — снова автофокус; **Alt+колёсико** — ручной перевод фокуса.

**Эффекты**
- **Анаморфотные блики** — длинные горизонтальные полосы от ярких источников (солнце, луна, светокамень, факелы, лава, морские фонари), цвет: синий, янтарный, нейтральный, фиолетовый; длина регулируется.
- **Блики линз (ghosts)** — отражения ярких источников, отражённые через центр кадра, и слабое гало.
- **Motion blur** камеры с регулируемым углом затвора (0–360°).
- Сетка третей (G) — видна даже при скрытом HUD, выключи её перед записью.
- В углу экрана — режим, мм, диафрагма, дистанция фокуса, наклон (выключается в панели или F1).

**NPC (5-я страница F9)** *(1.9)* — выбрать NPC: *Follow* — камера едет за ним (дистанция настраивается), *Its eyes* — вид его глазами, *Focus on this NPC* — автофокус держит его (режим AF *NPC*), *Save this shot* — запомнить текущий кадр для склеек на таймлайне.

Эффекты объектива работают и без *Cinematic Pipeline*; при включённом пайплайне к ним добавляется цветокоррекция.

## Шейдеры, тени, RTX и цветокоррекция

Всё включается в *Options → Shaders...* (или **F7** в игре). По умолчанию выключено — игра выглядит как ванильный Minecraft.

| Опция | Что делает |
|---|---|
| **Colored Light** | цветной свет блоков: лава и огонь — оранжевые, красный факел — красный, морской фонарь и маяк — голубые, светокамень — тёплый. Свет, проходящий через **цветное стекло**, окрашивается (красный витраж — красное пятно на полу). Обычные факелы остаются белыми, как в оригинале. |
| **Shadows** (Low / Medium / High / Ultra) | настоящие тени от солнца и луны (каскадные карты теней 1024–4096, до 320 блоков). Тени не «дрожат» при движении камеры. На закате длинные тени, ночью — слабые лунные. Тени отбрасывают и получают также сундуки, таблички, кровати, выпавшие предметы и сам игрок (его тень видна и от первого лица). Трава и цветы тень не отбрасывают. |
| **Ray Tracing** | трассировка лучей по вокселям мира в радиусе 128 блоков: точные тени от солнца (через цветное стекло — цветные), отражённый (переотражённый) свет от стен и пола, затенение небом в пещерах и между домами, отражения на воде. Шум убирается временным накоплением кадров. Дальше 128 блоков используются карты теней, если они включены. |
| **RT Quality** | Fast / Balanced / Quality — 1, 2 или 4 луча непрямого света на пиксель. |
| **Cinematic Pipeline** | HDR-буфер, свечение (bloom), цветокоррекция. |
| **Ambient Occlusion** | ползунок затенения углов и стыков блоков: 100% — как в Minecraft, 0 — выключено, до 200% — вдвое темнее. Для всего остального — **World AO** в *Effects...* (включено по умолчанию). |
| **Effects...** | эффекты шейдеров — отдельное окно, см. ниже: колышущаяся листва и трава, волны на воде, лучи солнца, отражения. |
| **Fog** | туман вкл / выкл. **Fog Distance** — где туман становится сплошным (4–256 блоков), **Fog Start** — с какой доли этого расстояния он начинается (0% — сразу у камеры), **Fog Color** — Sky (цвет неба, меняется днём и ночью), White, Grey, Blue, Smog, Green, Red, Black (ночью цвет темнеет). Небо уходит в туман, солнце, луна и звёзды в густом тумане пропадают. Сущности и облака тоже в тумане. Под водой — подводный туман, как раньше. |

### Эффекты: листва, вода, лучи, отражения

*Options → Shaders... → Effects...* (или **F7 → Effects...**). Каждый эффект включается кнопкой слева, ползунок справа — его сила (0–300%, 100% — по умолчанию; если двигать ползунок, эффект сам включается). *All Effects* включает и выключает всё сразу.

| Эффект | Что делает |
|---|---|
| **World AO** + сила | мягкое затенение (ambient occlusion) во всей игре, а не только в углах блоков: контактные тени под и вокруг выпавших предметов, сундуков, кроватей, табличек, 3D-моделей, игрока, NPC, машин, мобов, в щелях, нишах и под навесами — картинка перестаёт быть плоской. Считается по буферу глубины в половинном разрешении и размывается с учётом краёв (без ореолов вокруг силуэтов), вдали (64–128 блоков) плавно исчезает. **Включено по умолчанию**, 100% — обычная сила, до 200%. Рука от первого лица, предмет в ней, оружие и руки с ним тоже получают своё затенение (отдельный проход по их глубине: щели между магазином и корпусом, прицел, пальцы на цевье); интерфейс не затеняется. Работает без *Cinematic Pipeline*; ползунок *Ambient Occlusion* на главной странице по-прежнему управляет классическим затенением углов блоков, вместе они дают глубину как в шейдерпаках. |
| **Waving Plants** + **Wind** | ветер качает листву всех деревьев, траву, папоротники, цветы, саженцы, высокие растения (обе половины гнутся как одно целое, от корня), посевы, лианы; кувшинки покачиваются на воде. Порывы ветра волнами проходят по местности. Листья в соседних блоках двигаются согласованно — крона не рассыпается на щели. С тенями качаются и тени листвы. Время ветра — игровое: в меню паузы всё замирает, при записи видео в режиме *Smooth* движение идёт по часам видео. Грибы, паутина и сахарный тростник не качаются. |
| **Water: Waves** + **Wave Height** | живая поверхность воды: несколько систем волн разной длины бегут в разные стороны, отражение неба по Френелю (сверху вода прозрачная, у горизонта — зеркальная), солнечные и лунные блики на волнах (только там, где на воду падает солнце: в тени деревьев и под крышей бликов нет). Вдали мелкие волны сами затихают и вода становится гладкой — без ряби и мерцания. *Calm* (0%) — гладкое зеркало. |
| **God Rays** + **Rays** | лучи солнца и луны. **С включёнными тенями (Shadows)** — настоящий объёмный свет: в воздухе видно, куда достаёт солнце, — столбы света сквозь листву, окна и щели, даже когда само солнце за кадром; сильнее всего, когда смотришь в сторону солнца. **Без теней** — классические экранные лучи вокруг солнца, когда оно в кадре. Под водой выключаются. |
| **Reflections** (OFF / Water / Water + Blocks) + **Block Reflections** | отражения в экранном пространстве: в воде отражаются дома, деревья, NPC, облака, настоящее небо с солнцем (волны отражение колышут). *Water + Blocks* — ещё и глянцевые блоки: стекло (цветное — целиком, прозрачное — только рамка), лёд, железный и золотой блоки (отражение окрашено в цвет металла), алмазный, изумрудный, обсидиан, кварц, полированные камни, бетон, глазурованная терракота, призмарин. Полы блестят сильнее стен: матовые стены (бетон, кварц) отражают слабо, стекло и металл — в полную силу. Где отражаемое за краем экрана, подставляется небо, а под крышей — темнота. |

**Какие блоки блестят** — файл `game\reflections.txt` (создаётся при первом запуске): одна строка на блок, `имя = сила` от 0 (матовый) до 1 (зеркало), `*` — любой текст, например `*_concrete = 0.3` или `black_concrete = 0.6` (мокрый асфальт для ночной сцены). Блоки модов тоже можно вписать. После правки — кнопка *Reload reflections.txt* в окне эффектов (перезапуск не нужен).

Советы для съёмки: вода и отражения лучше всего смотрятся с *Cinematic Pipeline* (HDR: блики и солнце в воде дают bloom); лучи — с тенями *High* и выше. Отражения, лучи и волны работают и с *Ray Tracing*: вода тогда отражает через трассировку лучей (видно и то, что за кадром), а отражения на блоках и лучи — экранные. Экраны камер видеонаблюдения показывают волны и отражение неба, но без отражений мира и лучей.

### Пресеты и переходы (Left Alt + ,)

*Shaders → Presets & Transitions...* Переход плавно меняет весь вид картинки — шейдеры и цветокоррекцию (*Cinematic Pipeline*) — за выбранное время. Так снимаются смена погоды и настроения: солнечный день затягивает туманом, начинается шторм (ветер и волны растут, тени гаснут, бетон становится мокрым и блестит), вечер переходит в «холодную ночь».

- **From** / **To** — пресет шейдеров и пресет цвета. `<` `>` листают, клик по названию — следующий.
  - *Пресет шейдеров* — цветной свет, тени, трассировка лучей, AO, туман (дальность, начало, цвет) и эффекты (ветер, волны, лучи, отражения). Встроенные: **Vanilla, Sunny, Golden Hour, Overcast, Foggy Morning, Storm, Smog, Night City**. Свой: настрой шейдеры как нужно, впиши имя внизу окна и нажми *Save shaders as preset* — он сохранится в `game\shaders\<имя>.txt` и появится в списке.
  - *Пресет цвета* — пресеты цветокоррекции F6 (встроенные и сохранённые) или **Off** — *Cinematic Pipeline* выключен.
  - **(current)** у *From* — то, что на экране в момент запуска перехода.
- **Time** — длительность от 0,5 с до 5 минут; **Curve** — *Smooth* (плавный разгон и торможение) или *Linear*.
- **Show From** / **Show To** — сразу показать начальный или конечный вид (проверить пресеты перед дублем).
- В игре **Left Alt + ,** запускает переход From → To. Нажать ещё раз, когда он закончился, — переход обратно To → From. Нажать во время перехода — он развернётся с того места, где был. Переход идёт по игровому времени: в меню паузы замирает, при записи видео в режиме *Smooth* — точно по кадрам видео.

Что и как меняется: все числа плавно (туман, его цвет, AO и World AO, сила ветра, высота волн, лучей, блеск блоков, экспозиция, температура, контраст, насыщенность, тонирование, bloom, виньетка, зерно, кривые). То, что включено только в одном пресете, плавно проявляется или гаснет: тени, цветной свет, волны и отражения на воде, отражения, лучи, ветер, туман (из дальности прорисовки), *Cinematic Pipeline* (из нейтральной цветокоррекции). Разные тональные кривые (ACES, Filmic…) смешиваются, разные LUT сменяют друг друга через ноль. Качество теней на время перехода берётся большее из двух; трассировка лучей включается или выключается ровно на середине (плавно её не погасить).

Команда для пульта и сцен: `/transition` (запуск, как Left Alt + ,), `/transition 20` (за 20 секунд), `/transition to Storm / Cold Night`, `/transition from (current) / Off`, `/transition show from|to`, `/transition list`. Модам — `GraphicsApi.setTransition(...)`, `toggleTransition()`.

**Цветокоррекция (F6)** открывает панель слева, мир остаётся виден и меняется сразу:
- *Light*: экспозиция (EV), тональная кривая (Vanilla / ACES / Filmic / Reinhard), цветовая температура (K) и оттенок, контраст, Lift/Gamma/Gain.
- *Color*: насыщенность, вибрация, тонирование теней и светов (оттенок + сила), **LUT-файлы `.cube`** (положи в `game\luts\`, выбирай кнопкой LUT) и сила LUT.
- *Effects*: bloom, порог bloom, свечение светящихся блоков, виньетка, зерно плёнки.
- *Curves*: кривые как в Photoshop/Resolve — общая RGB и отдельно R, G, B, с гистограммой кадра. Клик — добавить точку, перетаскивание — двигать, ПКМ — удалить.
- Пресеты: Vanilla, Cinematic, Golden Hour, Cold Night, Bleach Bypass, Vivid, Noir, Teal & Orange; кнопки `<` `>` листают, **Save** сохраняет свой пресет в `game\grading\<имя>.txt` (файлы можно передавать друг другу).
- ПКМ по ползунку — сброс к умолчанию. **Удерживай Tab** — посмотреть кадр без цветокоррекции (до/после).

Интерфейс и HUD цветокоррекцией не затрагиваются, рука в кадре — затрагивается (как в шейдерпаках).

## Что нового в 1.14

**Эффекты шейдеров** (*Shaders → Effects...*, раздел «Эффекты: листва, вода, лучи, отражения»)
- **World AO** (включено по умолчанию): ambient occlusion для всей игры — предметы, модели, игрок, NPC, машины, мобы отбрасывают мягкие контактные тени, углы и щели темнеют не только у блоков; затеняются и рука, предмет в ней и оружие от первого лица.
- **Колышущаяся листва и трава**: ветер с порывами качает листья, траву, цветы, высокие растения, посевы, лианы и кувшинки; тени листвы качаются вместе с ней.
- **Волны на воде**: бегущие волны, отражение неба по Френелю, солнечные блики; вдали вода сама успокаивается без мерцания.
- **Лучи солнца (god rays)**: с тенями — объёмный свет сквозь листву и окна, без теней — лучи вокруг солнца.
- **Отражения (SSR)**: мир в воде и на глянцевых блоках — стекло, лёд, металлы, кварц, бетон…; какие блоки и насколько блестят — `game\reflections.txt`.
- Всё доступно модам (`GraphicsApi`: `setWavingPlants`, `setWaterWaves`, `setGodRays`, `setReflections`) и с пульта по Wi-Fi.
- **Пресеты шейдеров и переходы** (**Left Alt + ,**): плавная смена шейдеров и цветокоррекции из одного пресета в другой за заданное время — смена погоды, утро → туман, день → шторм. 8 встроенных пресетов погоды и свои в `game\shaders\`. Раздел «Пресеты и переходы».

**Огнестрельное оружие**
- Оружие из папок `game\guns\` (модель OBJ с частями и точками хвата, текстура, иконки, звуки `.ogg`/`.wav`, характеристики в JSON), стрельба, прицеливание, перезарядка с магазинами, отдача, динамичные анимации от первого лица и хват от третьего. Примеры — AK-12 и пистолет FP9. Подробно — раздел «Огнестрельное оружие».
- **Пистолетная анимация** (`reloadStyle: "pistol"`): хват двумя руками, магазин выскальзывает из рукоятки и падает, новый вдвигается снизу, затвор-кожух передёргивается сверху и остаётся сзади на пустом магазине (`slideLock`).
- **Ограничители затвора** `boltFront` / `boltBack`: затвор не уходит за пределы оружия; ход на выстрел — `boltShot`.
- **Удар прикладом** (СКМ с оружием): три вида — Jab, Swing, Smash, связкой одна за другой; у пистолета — удары рукояткой. Позы, время и урон правятся в редакторе (*View → Melee*), от третьего лица и в дублях тоже. Раздел «Огнестрельное оружие» → «Удар прикладом».
- **Шейдеры**: ползунок **Ambient Occlusion** и настраиваемый **туман** (дальность, начало, цвет).
- **Двери трескаются от пуль** (анимация добычи блока) и ломаются, когда урон пуль наберёт 30: с AK-12 — с 5-го выстрела, с FP9 — с 6-го.
- **Пули сбивают факелы**: факел разлетается и гаснет.
- **Редактор оружия переработан**: вкладки вместо длинных списков, отмена/повтор (Ctrl+Z / Ctrl+Y), ввод числа (Ctrl+клик), точное перетаскивание (Shift), копирование поз, *Hold at* для перезарядки и затвора, замедление анимаций, пресеты автомата и пистолета.
- **Скин игрока** (**Left Alt + F9**): любой скин из списка NPC (и свои из `game\skins\`) — на модели, руке от первого лица, руках с оружием и кулаках.
- **Снаряжение** (**Left Alt + E**): 3 + 3 подсумка на поясе, до 3 магазинов в каждом, перезарядка берёт оттуда первой; магазины видны на поясе от третьего лица.
- **Хедшоты** (урон × 2,5, красный крест), **пули выбивают куски и разваливают блоки** (*Bullets Break Blocks*), **камеры наблюдения разбиваются** — и любые будущие камеры тоже.
- **Ragdoll** для NPC и актёров, **кровь** от любого урона (брызги и пятна, больше при большем уроне; *Blood*), **машины сбивают** NPC и актёров, NPC получают урон от падения. Раздел «Огнестрельное оружие» → «Кровь, ragdoll, наезд машиной».
- Переходы пресетов шейдеров (**Left Alt + ,**, `/transition`, кнопка в меню) больше не пишут в чат «Transition A -> B» и «turned around»; в чате остаются только ошибки (не найден пресет).
- **Оружие на спине** (**Left Alt + F**): оружие из руки уходит за спину (автомат — наискось через спину, пистолет — за пояс), слот пустеет; ещё раз — правая рука тянется за спину, и оружие возвращается в тот же слот и в руку. Видно от третьего лица, в тени и в дублях NPC, сохраняется с миром. Раздел «Огнестрельное оружие» → «Оружие на спине».
- **Бой на кулаках** (**Left Alt + Q**): ЛКМ — левая, ПКМ — правая, прямые и хуки связками, стойка с теми же пружинными анимациями, что у оружия, хит-стоп при попадании, стойка и удары от третьего лица. Подробно — «Бой на кулаках».
- **Исправлено: руки расходились с оружием** в позах (особенно *Bolt*): сдвиг и поворот *Gun* в позе двигал оружие без рук, и рука на затворе или магазине промахивалась мимо. Теперь ладони всегда на своих точках нарисованного оружия, а *Arms* поворачивает руки вокруг кистей.

**Камеры и экраны**
- **Камеры видеонаблюдения** и **экраны-холсты**: камера ставится с кодом (паролем), холст вешается на любой блок или 3D-блок, подгоняется по размеру, положению, повороту и обрезке и показывает живую картинку камеры по её коду. Модели `security_camera.bbmodel` и `monitor.bbmodel` (в `game\3d\examples\`). Подробно — раздел «Камеры видеонаблюдения и экраны».

**Багчек и оптимизация**
- **Динамический свет** (факел в руке, на земле, в полёте) больше не оставляет чёрными стену прямо перед игроком и верх блока рядом: свет считался с учётом угла, а рука находится почти в стене и чуть выше её верха. Теперь грань получает свет воздуха перед собой, как в Minecraft, и угол не важен; сквозь стену на её обратную сторону свет по-прежнему не проходит.
- **Правки мира после автосохранения могли пропасть**: если чанк выгружался сразу после автосохранения (каждые 5 минут), а игрок быстро возвращался, игра читала с диска старую копию, пока новая ещё записывалась. Теперь автосохранение и выгрузка идут одним путём, и чанк берётся из памяти.
- **Дыра в мире**: чанк, который WorldEdit (`//set`, `//paste`) записал на диск, пока он подгружался, больше не остаётся незагруженным до тех пор, пока игрок не перейдёт в другой чанк.
- **Сохранения не портятся при сбое**: `blockids.txt`, `mobs.txt`, `moddata.txt`, `npc\actors.txt`, `vehicles.txt`, путь камеры и `options.txt` пишутся сначала во временный файл и заменяют старый одним шагом. Раньше вылет или полный диск посреди записи `blockids.txt` перемешивал все блоки мира.
- Автосохранение теперь пишет и данные модов (`moddata.txt`) — раньше они сохранялись только при выходе из мира; удалённые модом данные больше не возвращаются после перезагрузки.
- **Существа модов с `spawnsNaturally(..., "grass", "sand")` не появлялись никогда**: имена блоков сравнивались как `minecraft:grass` против `grass`. Приманка `temptedBy(...)` теперь узнаёт предмет и по имени с `minecraft:`, и без.
- Испорченный JSON (машина, модель Blockbench) больше не вешает игру: лишняя `]` или `}` раньше давала бесконечный цикл. Исправлены `\r`, `\b`, `\f` и неполные `\u` в строках.
- Пульт по Wi-Fi: после 8 неверных PIN подряд адрес блокируется на минуту (4-значный PIN подбирался перебором, в том числе через `/ping`); новый PIN генерируется криптостойким генератором.
- Выпавший предмет, который как раз исчезает (5 минут), больше не «съедает» соседние стопки при слиянии.
- Большой сундук: добавление предметов через общий код инвентаря (`add`, `isEmpty`, `clear`) работает с обеими половинами.
- `/vehicle models` показывает имя машины из настроек (`"name"`), если оно отличается от папки.
- Оптимизация: цветокоррекция больше не собирает каждый кадр строку из всех точек кривых; меш секции не создаёт массивы на каждый блок травы и на каждую пустую секцию; модели игрока, NPC и брони не создают таблицы коробок каждый кадр; биом чанка загружается без нового буфера на каждый чанк; поиск верхнего блока начинается с верхней непустой секции.

- Мечи режут быстрее только растения, листву, лозы, тыквы и арбузы (как в 1.12), а не всё подряд.
- Износ как в 1.12: инструменты −1 за блок, мечи −2; за удар меч −1, остальные инструменты −2; ножницы тратятся только на своих блоках. Лук, огниво и броня в руке больше не изнашиваются от копания и ударов.
- Мультиинструменты для модов: `ItemBuilder.alsoTool(...)` (paxel = кирка + топор + лопата), см. MODDING.md.
- NPC с инструментом в руке ломают блоки быстрее.

**Оптимизация**
- Мешинг секций в ~1,7 раза быстрее (тот же результат до бита): данные секций копируются блоками, а не по клетке.
- Пустые секции (небо над рельефом — в обычном мире около 90% секций) больше не гоняются через фоновые потоки.
- Выбор секций для мешинга не перебирает и не сортирует всю очередь каждый кадр — меньше фризов при загрузке на дальности 32–64.
- Загрузка и сохранение чанков: распаковка и сжатие идут параллельно на всех ядрах (раньше всё ждало одну блокировку).
- Видеобуфер чанков: выделение места за O(log n) по размеру (best-fit) вместо перебора всех свободных кусков.
- Тени: при неподвижной камере и остановленном времени (`/time stop`) карты теней рельефа не перерисовываются каждый кадр.
- Выпавшие предметы вне кадра не рисуются.
- Ограничитель FPS держит ровный темп кадров (раньше на Windows шаг сна 1–15 мс давал рваный ритм на записи).
- Generational ZGC: меньше работы сборщика мусора.
- **Таблица чанков**: у ключа чанка был плохой хэш (`cx ^ cz`): при дальности 64 на ~16 000 чанков приходилось всего ~256 разных хэшей, и каждое чтение блока шло через поиск по дереву. Теперь ключ перемешан, а игровой поток помнит последний чанк. Чтение блока (на нём стоят физика, лучи, ИИ, огонь, частицы) в 4–6 раз быстрее, тем больше, чем больше дальность.
- **Коллизии и хитбоксы**: физика игрока, мобов, тел NPC, предметов и падающих блоков в ~30 раз быстрее при том же результате до бита (проверено на мире из всех блоков вперемешку: заборы, стены, ступеньки, двери, калитки, лестницы, приседание, позы, подъём на ступеньку). Формы блоков кешируются, коробки собираются один раз за шаг (раньше до 20 раз при приседании у края), читаются только клетки, до которых формы реально достают (а не лишний блок со всех сторон), без массивов на каждую коробку.
- Луч прицела, пули, снаряды, прицел по предметам и машинам — без временных массивов, в ~5 раз быстрее.
- Мешер сразу отбрасывает секции глубоко в камне (всё вокруг — сплошные блоки): раньше каждая проходила полный перебор 4096 клеток × 6 сторон. Меши те же до бита.
- Секции рельефа отсекаются по пирамиде видимости и для теней по коробке своей геометрии, а не по целому кубу 16³ (у поверхности это часто пара слоёв земли и трава).

## Пауза в меню

Одно правило для всех меню: **служебные меню ставят мир на паузу, как Esc** — NPC Hub, панель камеры (F9), таймлайн (пока сцена не играет), шейдеры, цветокоррекция, Model Hub, настройки 3D-блока и сцен-блока, все настройки. Мир при этом рисуется, но не двигается совсем: замирает и промежуточный кадр между тиками, поэтому камера не дёргается, даже если открыть меню на бегу. Изменения объектива на панели камеры (зум, крен, фокус) видно сразу. Игровые меню (инвентарь, сундуки, печка, таблички, книги, чат, экран смерти) мир не останавливают.

## Оптимизация (что внутри)

- **Greedy meshing**: одинаковые грани соседних блоков (с одинаковым освещением и AO) сливаются в один большой прямоугольник. Сплошная стена небоскрёба — это несколько четырёхугольников, а не тысячи.
- **Один общий видеобуфер** для всех чанков и **glMultiDrawElementsIndirect**: весь мир рисуется тремя вызовами отрисовки (непрозрачное, вырезанное, полупрозрачное).
- Грани каждой секции 16³ разбиты по направлениям; группы, повёрнутые от камеры, вообще не отправляются на GPU (примерно половина граней).
- Компактная вершина — 12 байт, координаты относительно камеры (нет дрожания вдали от центра мира).
- Отсечение по пирамиде видимости и по дальности, сортировка спереди назад.
- Генерация, загрузка и мешинг идут **на всех ядрах** (на i7-12700H — 18 потоков), освещение — в отдельном потоке, загрузка в GPU — с лимитом времени на кадр, без фризов.
- Сборщик мусора ZGC (паузы меньше миллисекунды) и 6 ГБ памяти под мир.
- Мир хранится в регион-файлах со сжатием (сжатие и распаковка параллельно на всех ядрах); автосохранение в фоне.
- Пустые секции не мешируются вовсе, карты теней переиспользуются, пока ничего не изменилось *(1.14)*.
- **Коллизии** (`world/Collision`): формы блоков кешируются по (meta, соединения), коробки вокруг тела собираются в один плоский буфер один раз за шаг, просматриваются только клетки, до которых достают формы блоков (`Block.collisionReach`: заборы и стены — на полблока вверх). Общий тест «луч — коробка» (`util/RayBox`) для всех хитбоксов.
- **Частицы**: до 20 000 одновременно. Мёртвые убираются одним проходом (раньше удаление по одной было квадратичным и при тысячах частиц съедало кадр), свет у каждой частицы считается раз в два тика, а не каждый кадр, частицы вне экрана и дальше 192 блоков не рисуются, вершины пишутся сразу в буфер без временных массивов.

Советы: для съёмки ставь *VSync: ON* (ровный темп кадров; во время записи в режиме *Smooth* игра сама держит темп видео); для сцен с огромными городами можно поднять дальность до 32–48 чанков, на RTX 3060 это должно работать комфортно. Свободную видеопамять показывает F3.

## Что умеет мир

- Генерация в стиле 1.12: океаны, пляжи, равнины, леса, берёзовые рощи, пустыни, горы, заснеженная тайга, деревья, цветы, руды. Есть плоский мир (*World Type: Superflat* в *More World Options...*) — идеален для городов.
- 350+ блоков 1.12 и 520+ предметов: все цвета шерсти, бетона, терракоты, стекла, полублоки и ступеньки, заборы, стены, панели, решётки, ковры, растения, инструменты, броня, еда.
- **Рабочие блоки**: сундуки (одинарные, двойные, с ловушкой, эндер-сундук с общим содержимым) с анимацией крышки, печь (топливо, плавка, опыт, светится когда горит), верстак (рецепты 1.12.2), раздатчик, выбрасыватель и воронка как хранилища, двери (двойные открываются парой), люки, калитки, лестницы, лианы, рычаги, кнопки, нажимные плиты (открывают двери/люки и включают лампы рядом — упрощённый редстоун), таблички с текстом, кровати (сон ночью, точка возрождения), пашня, пшеница/морковь/картофель/свёкла растут, саженцы вырастают в деревья, трава разрастается, костная мука, горшки с цветами, торт, огонь, рельсы.
- **Выживание**: здоровье, голод и насыщение, урон от падения, лавы, огня, кактуса, утопления; броня; время добычи зависит от инструмента и его уровня, инструменты изнашиваются, блоки без нужного инструмента не дают дроп; выпавшие предметы подбираются; экран смерти и возрождение; опыт от печи.
- Режим выбирается при создании мира (*Game Mode*) или командой `/gamemode`.
- **Выпавшие предметы** (*Options → Gameplay...*): *Item Physics* — предметы ложатся плашмя на землю и кувыркаются в полёте (выкл. — крутятся и подпрыгивают, как в ванилле); *Item Pickup* — *Automatic* (подходишь — предмет подлетает к тебе, как в оригинале) или *Click* (наводишь прицел на предмет, ЛКМ — персонаж взмахивает рукой и предмет быстро прилетает в инвентарь).
- **Вид от третьего лица (F5)**: модель игрока со всеми анимациями (ходьба, взмах рукой, присед, поворот головы, предмет в руке), камера не проходит сквозь стены; расстояние камеры настраивается в *Gameplay* (1–16 блоков) — удобно для съёмки.
- Освещение как в Minecraft: небо + блоки (0–15), сглаженное освещение, ambient occlusion, цикл дня и ночи, звёзды, фазы луны, рассвет, объёмные облака, туман, тонировка травы и листвы по биомам.

Не сделано (по ТЗ): мобы, полноценный редстоун. Ещё нет звука и текущей воды (вода и лава статичны).

## Моды

API для модов уже встроен: свои блоки, предметы, рецепты, команды, события, клавиши, HUD; с 1.5 — функциональные блоки без лишнего кода (хранилища на 1–54 слота с автоматическим окном, «постоянные» чемоданы и сейфы, печи и свои машины, таблички и экраны с текстом, свои модели), свои окна, данные блоков/предметов/мира, порядок загрузки модов; NPC и записанные актёры, а с 1.3 — управление камерой, шейдерами и цветокоррекцией.

**С 1.7 мод может всё, не переписывая игру:**
- **Патчи кода игры** (как Mixin в Fabric/Forge): вставить свой код в начало или конец любого метода, заменить метод, поменять аргументы, результат, вызов внутри метода или число в коде. Игра запускается через `derpcraft.Launch` (Play.bat делает это сам), и классы игры загружаются уже изменёнными.
- **События почти на всё**: урон и смерть игрока, существ и NPC, появление существ, взрывы, попадания снарядов, клавиши, мышь, открытие окон, подбор предметов, команды, закрытие мира — с отменой и изменением.
- **Существа**: свои модели (как в Minecraft/Blockbench, готовые человек, четвероногое, куб), враждебные, нейтральные и мирные, стрелки, поиск пути, горение на солнце, добыча и опыт, естественное появление ночью/днём, яйца призыва, сохранение в мире. Враждебные существа нападают и на NPC, а NPC-стражи защищают игрока от существ.
- **Снаряды и взрывы**: бросаемые и стреляющие предметы, отскоки, поджигание, взрывы как у TNT.
- **Генерация мира**: руды и любые свои постройки в новых чанках.

Команды: `/mob summon <тип> [кол-во]`, `/mob list`, `/mob kill [тип|all]`, `/mob types`, `/mob spawning on|off`, `/mob explode [сила]`.

Подробно — в **[MODDING.md](MODDING.md)**, готовые примеры с исходниками — `examples\Creatures` (существа, снаряды, события, генерация, патч кода), `examples\ModernBlocks` (функциональные блоки) и `examples\CineMod` (камера и NPC), собираются `build-mod.bat`.

## Для Claude: что недоступно в облачной среде

Памятка для новых сессий Claude (облачный контейнер claude.ai / Claude Code), чтобы не тратить время и токены на поиски. Проверено 2026-11-02/03.

**Не работает — не пробовать:**
- **Maven Central** (`repo1.maven.org`) закрыт прокси (403). Скачать LWJGL, ASM и другие зависимости нельзя, `gradlew build` не соберётся.
- **LWJGL на GitHub** нет готовых jar: релизы lwjgl3 публикуются на lwjgl.org / Maven, а не в GitHub Releases. Сгенерированных GL-биндингов в исходниках репозитория тоже нет. `gh release`/GraphQL в сессии запрещены (403), остаётся только REST `gh api`.
- **Запустить игру нельзя**: нет экрана, нет OpenGL 4.3+, нет LWJGL.
- **Видеокарты NVIDIA / CUDA нет**: NVENC (`h264_nvenc`, `hevc_nvenc`) падает с «Cannot load libcuda.so.1». Можно проверить только то, что ffmpeg принимает параметры.
- Сайты для скачивания ffmpeg под Windows (gyan.dev, BtbN) тоже недоступны: положить `ffmpeg.exe` в архив нельзя.

**Работает:**
- JDK 21 (`javac`, `java`), Python 3, ffmpeg/ffprobe (с libx264), pip и npm.
- **Проверка компиляции без библиотек**: `sh tools/check_compile.sh`. Скрипт компилирует всё обычным `javac` и показывает только настоящие ошибки, отбрасывая ошибки из-за отсутствия LWJGL/ASM (их около 1150–1200, это норма). Ответ «OK» значит, что код в порядке.
- Код без OpenGL (например, `derpcraft.record.ScreenRecorder`) можно скомпилировать отдельно и прогнать с настоящим ffmpeg.
- Код с OpenGL проверяется только компиляцией. Перед сдачей стоит сверить имена функций GL45C/GLFW с документацией LWJGL 3.3.4.
- Звуки `.ogg` декодирует `lwjgl-stb` (stb_vorbis): зависимость добавлена в `build.gradle`, в облаке её тоже нет, код проверяется только компиляцией.
- **2026-11-04: `repo1.maven.org` открылся** (`repo.maven.apache.org`, через который ходит Gradle, отвечает 429). Jar LWJGL/ASM качаются напрямую `curl` с повторами (на 429 — подождать несколько секунд), и вся игра компилируется обычным `javac` без ошибок — это делает `sh tools/perf_check/check.sh` (там же замеры и проверка «тот же результат» для коллизий, лучей и мешера без запуска игры, см. `tools/perf_check/README.md`). Gradle по-прежнему не собирает.
- **2026-11-04: игру можно запустить и без видеокарты**: Xvfb + Mesa llvmpipe дают OpenGL 4.6, LWJGL-natives для Linux качаются с `repo1.maven.org`. `sh tools/smoke_check/run.sh` стартует настоящую игру, играет сценарий (машины, редактор, камера) и кладёт скриншоты в `/tmp/dc_smoke/shots`; смотри их через Read. Подробно — `tools/smoke_check/README.md`.
- **Шейдеры GLSL** можно проверить и даже прогнать в headless Chromium через Playwright (WebGL2 на SwiftShader): заменить `#version 330 core` на `#version 300 es` + `precision highp float; precision highp int;`, отрисовать в FBO и сравнить `readPixels` с эталоном. Так проверен `record_yuv.fsh` (байт в байт с эталоном на Java, который сверен с ffmpeg).

## Оригинальные звуки Minecraft (`game\sounds`), полный список путей и что подключено — SOUNDS.md, проверка — `/sound`
Папку `sounds` из ассетов 1.12 (`dig`, `step`, `damage`, `random`, `mob`, `block`...) кладите в `game\sounds` как есть (`game\sounds\dig\stone1.ogg`).
