# DerpCraft: заметки для Claude

Игра на Java 21 + LWJGL 3.3.4 (OpenGL 4.3+, GLFW), сборка Gradle (`build.bat` у пользователя на Windows).
Пользователь проверяет и запускает игру сам; присылает проект архивом и получает его обратно архивом.

Перед работой прочитай раздел README.md **«Для Claude: что недоступно в облачной среде»**. Кратко:
- Maven Central закрыт (403): LWJGL/ASM не скачать, Gradle не соберёт, игру не запустить. На GitHub LWJGL jar тоже нет, не ищи.
- Нет видеокарты NVIDIA/CUDA: NVENC не проверить.
- Проверка кода: `sh tools/check_compile.sh` (показывает только настоящие ошибки компиляции).
- ffmpeg/ffprobe, JDK 21 и Python есть локально.
- Полная компиляция с настоящими LWJGL/ASM и замеры без GPU: `sh tools/perf_check/check.sh bench|equiv|mesh` (jar качаются с `repo1.maven.org`).

Коллизии и хитбоксы (1.14): общий код — `world/Collision` (`collect` в плоский буфер `Boxes`, `clip`, `overlaps`, `solidAt`); формы блоков — только через кеш
`Block.collisionShape/selectionShape(meta, conn)` (переопределяют по-прежнему `collisionBoxes/selectionBoxes`; списки общие, не менять; мод поменял модель — `shapesChanged()`);
насколько формы вылезают из клетки — `Block.collisionReach()` (считается в `Blocks.freeze`). `Player.move` собирает коробки один раз на весь шаг (включая подъём на ступеньку и край при приседании).
Луч — коробка: `util/RayBox.t` (мобы, NPC, игрок, машины, предметы). Видимость NPC/мобов — `Raycast.clearLine` (закрывают только сплошные кубы). Ключ чанка `Chunk.key` перемешан (не раскладывать обратно в координаты), `World.getChunk` помнит последний чанк игрового потока — после `chunks.put/remove` вызывать `world.chunksChanged()`.
Мешер: `ChunkMesher.buried` отбрасывает секции в сплошном камне, `Mesh.bounds` — коробка геометрии (отсечение секций в `WorldRenderer.draw/drawShadow`). После правок физики/мешера — `perf_check equiv` и `mesh` на старой и новой копии, хэши должны совпасть.

Проверка папки — `sh tools/gun_check/check.sh <папка>` (части, точки, настройки, звуки, руки не растягиваются и ладони на точках, магазин и затвор
при перезарядке, прицел в центре). **Картинки поз** — `sh tools/gun_check/preview.sh <папка> [выход]` → `sheet.png`

магазин красным, затвор жёлтым). Смотри их после любой правки анимаций (крупно — `python3 -I tools/gun_check/sheet.py <папка> <кадр> ...` → `big.png`). Числа до/после правки — `sh tools/gun_check/tests.sh <папка>`. Всё про инструменты — **`tools/gun_check/README.md`**.

ключевые кадры перезарядки, `armMatrix`, темп `animSpeed`; без GL), `GunController` (стрельба, перезарядка, preview для редактора), `Guns`
(папки, предметы, `/gun`·`/guns`, `reload()` без перезахода, `watch()` следит за файлами), `gui/GunEditor` (Alt+Home),

Новый параметр оружия = одна строка в `GunType.PARAMS` (в редакторе он сам попадает на свою страницу; вкладку страницы решает `GunEditor.inPageTab`). Руки: ладони считаются от **нарисованного** оружия `Pose.gun` (= «Gun»-сдвиг поз вокруг рукоятки × риг `m`), поэтому никакая поза не отрывает их от точек (`tests/HandsTest`); `armsMove` поз не двигает ладони, а сдвигает, откуда идут руки (`ARMS_SWING`); оторвать ладонь можно только `armRight/LeftOffset` и `r/lArmMove`. Затвор: ходит по отрезку `boltFront`→`boltBack` (точки в `points`, авто — задний торец `slide` + ход), `t.boltDir`/`t.boltTravel`, сдвиг точки — `t.boltPoint(p, slide)`; `Pose.slide` — расстояние вдоль `boltDir`, всегда в [0, boltTravel]; `boltShot` — доля хода на выстрел, `slideLock` + `GunAnimator.boltLocked` — кожух сзади на пустом (`LOCK`). Перезарядка: `reloadStyle` rifle/pistol (`GunType.pistol`): `GunAnimator.reloadState(t, r, empty)` → у пистолета `pistolState` (магазин вдоль `t.magAxis` — главная ось вершин `mag`, `magOut` в длинах магазина, рука сразу к карману — `Reload.toPocket`; моменты событий те же: `MAG_OUT/MAG_DROP/POCKET/MAG_INSERT/MAG_IN`), матрицы — `magMatrix(..., rs)`, `releaseMatrix`, `insertMatrix`. Повороты кисти на магазине / затворе — `magHandRotation` / `boltHandRotation` (страница параметров "Hands", в редакторе — Arms → Hands → Mag / Bolt; вес — `magW` / `boltW`). Отпущенный магазин в 1-м лице падает в кадре — `GunAnimator.dropMagazine` (`Pose.dropMag` / `dropMagShown`, скорость из последнего кадра + гравитация по взгляду). Пресеты поз — `GunType.posePreset` (`PISTOL_PRESET` = позы FP9). Редактор: вкладки (`TABS`), undo/redo — снимки `GunType.toJson()` / `fromJson()` (стек на оружие), `GunController.previewAt` (Hold at), `previewSpeed` (замедление, превью-перезарядка идёт по своему времени), `previewBolt` (затвор на Points), `Pose.marker2` (вторая точка пары). Пример пистолета — `resources/guns/fp9` (+ `game\guns\fp9`), примеры ставятся по одному разу — список в `game\guns\.examples` (`Guns.EXAMPLES`). Позы (`GunType.POSES`: hip, aim, sprint, reload, bolt, aim2 — индекс `AIM2` = 5, второй прицел по `Keys.AIM2`, Alt; прицелы строит `GunAnimator.aimPose`: точка `sight`/`sight2` в центре, поворот вокруг неё) — массивы `poseMove/poseTurn` (весь риг), `gunMove/gunTurn` (оружие с ладонями на нём: `Pose.gun` = сдвиг вокруг рукоятки × риг `m`, кисти считаются от `Pose.gun`), `armsMove` (руки поворачиваются вокруг кистей); веса смешивания — те же, что у поз. В редакторе позу держит `GunController.previewPose`. Позы sprint/reload/bolt (весь риг, только оружие, только руки) идут через `GunAnimator.smoothPose` (SmoothDamp, время растёт с величиной позы, множитель `poseSmooth`); hip↔aim — по `aimTime`; толчки (щелчок магазина, затвор) — пружина `rel`. Рамка бокса руки в `GunAnimator.armMatrix` повторяет руку ModelBiped (поднятую вперёд): грань -x бокса (снаружи у правой руки, внутри у левой) смотрит вправо, перед (-z) — вверх; не переворачивать. Эффекты шейдеров (*Shaders → Effects*, `gui/Graphics.Effects`, настройки `Settings.waving/windStrength/waterShader/waveHeight/godRays/godRayStrength/reflections/blockReflections`):
таблица материалов на слой текстуры — `Assets.buildEmissive` (RGBA8: r свечение, g флаги 255 вода / 100 огонь, b класс ветра `WAVE_*`, a блеск из `game\reflections.txt`).
Ветер — `shaders/wave.glsl` (в `terrain.vsh` и `shadow.vsh`; все частоты кратны 2π/1024, позиция берётся `& 1023` без шва; растения гнутся от корня по v текстуры), часы — `WorldRenderer.wave/waveTime` (игровое время), ближний каскад теней перерисовывается, пока идёт ветер (`ShadowRenderer`, `cachedWaveTime`).
Вода — `terrain.fsh` `waterNormal` (волны гасятся по размеру пикселя), блики, отражение неба; при SSR небо в воде рисует пост. SSR и лучи — `PostProcessor.screenEffects` (после `temporal`, до `lensPass`): материал пишется во 2-е вложение сцены (`fragMaterial`: окта-нормаль, вид 1..63 блок / 64 вода + небо·0.9, расстояние — по нему пост отбрасывает пиксели, закрытые сущностями), `post_ssr.fsh`, `post_godrays.fsh` (с тенями — объёмный по картам теней, без — радиальный), `post_blur.fsh`.
Проверка шейдеров без GPU: `node tools/shader_check/compile.js src/main/resources/shaders` (компиляция в WebGL2) и `render.js` (синтетическая сцена для SSR/лучей/волн) — `tools/shader_check/README.md`.
Переходы (Left Alt + `Keys.TRANSITION`, `/transition`, `gui/Graphics.Transitions`): пресет шейдеров = `game/ShaderLook` (поля настроек шейдеров, текст как options.txt, встроенные `BUILTIN`, свои в `game\shaders\`), движок — `game/LookTransition` (`DerpCraft.transition`, `update` из `Session.render` по `frameSeconds`, 0 в паузе): каждый кадр пишет смесь в `Settings` и `game.grading` (`Grading.blend`: числа, оттенки по короткой дуге, кривые через bake, LUT через ноль, тональные кривые — `tonemap2/tonemapMix` в `post_final.fsh`), «плавные включения» — временные поля `Settings.coloredLightMix/shadowFade/waterFade/ssrWaterFade/fogTintFrom/fogTintMix` (не сохраняются; → `FrameParams.shadowFade/waterFade`, `uShadowFade` в lighting.glsl, `uWaterFade`, `uSSRWater` как доля), в конце `finish` ставит точный пресет.
World AO (SSAO, `Settings.ssao/ssaoStrength`, по умолчанию вкл., `worldAO()` → включает FBO-путь): `PostProcessor.ambientOcclusion` (после мира и сущностей, до `screenEffects`) — `post_ssao.fsh` (половинное разрешение в `dofA`: r = видимость, g = линейная глубина; нормали по точным центрам пикселей `texelFetch` — центры половинного разрешения лежат между пикселями, иначе полосы на земле; 60000 вместо бесконечности — предел fp16) и `post_ssao_apply.fsh` (4x4 размытие с учётом глубины + умножение блендингом; глубина на время прохода отцепляется от FBO сцены — иначе петля обратной связи).
